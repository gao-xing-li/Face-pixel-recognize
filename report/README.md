## 关键结果与证据口径

1. **实验三初版独立测试结果**：在 32 张独立测试图上，Precision 为 `66.42%`，Recall 为 `75.55%`，全局 F1 为 **`70.69%`**，IoU 为 **`54.67%`**（唯一的未见测试集一次性评估结果）。
2. **实验三形态学补全对比**：在原测试集上加入 $41\times41$ 膨胀—填孔—腐蚀后，Recall 升至 `79.55%`，Precision 降至 `63.63%`，全局 F1 为 **`70.70%`**（开发后测试对比，揭示颜色与无边界形态学的精确率—召回率等值线瓶颈）。
3. **实验四双椭圆约束与低支持重建（32 张验证集开发结果）**：在严格固定于 32 张验证集（开发集）的多轮迭代与消融中，相比实验三验证集基线（Precision `64.86%`、Recall `82.70%`、全局 F1 `72.70%`、IoU `57.11%`），实验四最终方案（试验 2C：严格优先/放宽回退双眼定位 + 正中/侧向双椭圆 $\lambda_{\text{in}}=0.82, \lambda_{\text{out}}=1.20, \Delta S_{\text{lat}}=0.06$ + $\rho_{\text{in}}<0.18$ 触发 $k=2.00$ 与 27 核闭运算受限重建 + 内 11 / 环带 5 分区形态学连接）将验证集指标提升至：
   - Precision：**`79.88%`**（+15.02 个百分点）
   - Recall：**`86.15%`**（+3.45 个百分点）
   - 全局 F1：**`82.89%`**（+10.19 个百分点）
   - IoU：**`70.79%`**（+13.68 个百分点）
   - 逐图平均 F1：**`82.19%`**（+11.52 个百分点，32 张图中 29 张提升、2 张微降、1 张无眼回退持平）
