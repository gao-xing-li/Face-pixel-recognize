## 报告结构

报告将前期实验（实验三）简要归纳为第 1 章背景回顾，第 2 至 6 章独立、完整地展开实验四的各阶段工作：

| 章节 | 源文件 | 内容概要 |
| --- | --- | --- |
| 第 1 章 | `sections_new/01_intro.tex` | 前期工作回顾与实验动机（数据集与标签映射、实验三颜色分割与补全结果简述、实验四改进方向） |
| 第 2 章 | `sections_new/02_data.tex` | 最大连通域分阶段检查与直接轮廓椭圆尝试（分阶段像素对照、弱开闭预操作与直接轮廓拟合局限） |
| 第 3 章 | `sections_new/03_model.tex` | 基于灰度黑帽变换与位置窗口的双眼定位（黑帽暗斑提取、三轮定位对比、均值诊断对照、两级面积比回退） |
| 第 4 章 | `sections_new/04_test.tex` | 由双眼生成脸部椭圆与内外双椭圆空间约束（双眼局部坐标系、五参数中位数先验、侧向姿态椭圆候选、内外嵌套双椭圆分工） |
| 第 5 章 | `sections_new/05_completion.tex` | 低支持度放宽肤色重选与分区形态学连接（内椭圆像素不足判别、$k=2.00$ 放宽阈值与 27 核闭运算受限重建、内外分区连接） |
| 第 6 章 | `sections_new/06_boundary.tex` | 验证集结果对照、消融分析与样本讨论（各轮消融结果、P-R 工作点图、典型样本对照与当前局限） |
| 第 7 章 | `sections_new/07_conclusion.tex` | 实验总结 |
