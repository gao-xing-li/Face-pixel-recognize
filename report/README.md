## 关键实验结果

1. **实验三基础颜色分割结果**：在 32 张测试图上，$k=1.25$ 矩形阈值配合最大连通域与填孔取得 Precision `66.43%`、Recall `75.55%`、全局 F1 **`70.69%`**、IoU **`54.67%`**（比纯阈值基线分别提高 8.03 和 9.04 个百分点）。
2. **实验三形态学补全分析**：加入 $41\times41$ 膨胀—填孔—腐蚀后，测试集 Recall 升至 `79.55%`（+4.00 个百分点），Precision 为 `63.63%`，全局 F1 为 **`70.70%`**，定量揭示了无几何约束形态学在精确率—召回率等值线上的平移特性。
3. **实验四双椭圆约束与低支持重建**：相比实验三在 32 张验证集上的基线（Precision `64.86%`、Recall `82.70%`、全局 F1 `72.70%`、IoU `57.11%`），实验四最终方案（严格优先/放宽回退双眼定位 + 正中/侧向双椭圆 $\lambda_{\text{in}}=0.82, \lambda_{\text{out}}=1.20, \Delta S_{\text{lat}}=0.06$ + $\rho_{\text{in}}<0.18$ 触发 $k=2.00$ 与 27 核闭运算受限重建 + 内 11 / 环带 5 分区形态学连接）将验证集指标提升至：
   - Precision：**`79.88%`**（+15.02 个百分点）
   - Recall：**`86.15%`**（+3.45 个百分点）
   - 全局 F1：**`82.89%`**（+10.19 个百分点）
   - IoU：**`70.79%`**（+13.68 个百分点）
   - 逐图平均 F1：**`82.19%`**（+11.52 个百分点，32 张图中 29 张提升）
