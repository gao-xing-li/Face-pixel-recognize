\begin{abstract}
本报告在前期基于 YCrCb 颜色空间的人脸分割实验（实验三）基础上，围绕“减少最大连通域筛选造成的脸部碎片丢失”与“抑制头发、脖颈等粘连区域的误检扩张”两个方向展开后续改进（实验四）。前期实验使用 162 张带像素级标签的 $512\times512$ 人脸图像（按 98/32/32 划分为训练集、验证集与测试集），采用 $k=1.25$ 的 Cr/Cb 矩形阈值配合最大连通域筛选与内部填孔，在测试集上取得全局 F1 70.69\%，在验证集上取得全局 F1 72.70\%；继续加入 $41\times41$ 膨胀—填孔—腐蚀补全后，召回率有所上升但精确率同步下降，F1 基本不变。

针对这一现象，实验四固定在 32 张验证集上逐步开展实验。首先对比了最大连通域筛选前后的像素变化，并尝试在原始阈值、$5\times5$ 闭运算和 $5\times5$ 开运算结果上直接拟合肤色轮廓椭圆；观察发现，待修整的肤色轮廓本身容易被粘连背景拉偏或局限于局部小碎片，简单开闭预操作也难以同时兼顾连接与分离。随后转向利用灰度图的明暗特征定位双眼：通过灰度黑帽变换提取眼部暗斑，结合训练集统计出的左右眼搜索窗口与两级面积比回退规则，在 31 张验证图上获得双眼配对，1 张无配对样本回退至实验三结果。在此基础上，以双眼中点、眼距和倾角生成正中及左右侧向偏移的候选椭圆，并按 $0.82$ 与 $1.20$ 倍轴长构造内外嵌套双椭圆：外椭圆裁剪越界的头发与脖颈误检，过渡区仅做 $5\times5$ 弱闭运算，内椭圆做 $11\times11$ 闭运算与填孔；当内椭圆中的原有掩膜占比低于 $0.18$ 时，在内椭圆内将肤色阈值放宽到 $k=2.00$ 并结合 $27\times27$ 闭运算与种子连通过滤恢复缺失内脸。在 32 张验证图上，改进流程将全局 Precision 从 64.86\% 提高到 79.88\%，Recall 从 82.70\% 提高到 86.15\%，全局 F1 从 72.70\% 提高到 82.89\%，IoU 从 57.11\% 提高到 70.79\%。

\noindent\textbf{关键词：}人脸分割；YCrCb 颜色空间；黑帽变换；双眼定位；双椭圆约束；形态学操作
\end{abstract}
