# Lab4：最大连通域分阶段对照

本实验复用 Lab3 的肤色统计、颜色阈值 `k=1.25`、标签定义和数据划分。只研究最大连通域筛选与普通填孔的关系。

| 问题 | 对照 | 如何读差异图 |
| --- | --- | --- |
| 最大连通域删除了哪些像素？ | 阈值掩膜 vs. 只保留最大 8 连通域 | 橙色是被删掉的正确脸部像素，青色是被去掉的非脸误检 |
| 跳过筛选后，同样填孔会怎样？ | 直接填孔 vs. 保留最大连通域后填孔 | 橙色是跳过筛选后多检出的脸部像素，青色是新增的非脸误检 |

差异图的灰色是变化落在忽略区，黑色是无变化。两行使用不同对照：筛选时删掉的部分像素可能已被后续填孔补回。填孔用现有实现，颜色阈值与填孔保持一致，未使用 41×41 补全。

图册覆盖 162 张图（验证 32、原测试 32、训练 98），默认打开验证集，按误删正确脸部像素数排序。原测试集仅用于解释既有失败，不参与本实验参数选择；训练图仅用于描述。页内同时给出逐图指标和各划分的像素汇总。
