# Lab4 黑帽运算与眼睛配对实验

目标：尝试从原图中找到双眼的位置，检查能否为后续椭圆提供比肤色轮廓更可靠的位置和方向信息。当前只到眼睛定位与可视化，不计算新椭圆，也不运行椭圆后的修整。

在仓库根目录运行：

```powershell
python experiments/lab4/eye_check/build_gallery.py --output results/lab4_eye_position_prior_20261108
```

固定运行清单中的 32 张验证图。离线打开输出目录的 `index.html`，可逐图查看加入先验前后首选结果、筛选改善或退步图、切换前三块的搜索范围，以及查看前五个配对。每张图另有六图总览 `assets/<id>/overview.jpg`。分享时复制整个输出目录。此前无位置先验的结果保留在 `results/lab4_eye_check_20261108/`。

## 方法和起步参数

1. 沿用 Lab3 肤色统计与 k=1.25，取**原始肤色掩膜面积前三个连通块**，不先做开闭运算；各块包围框向四周扩展 12%。扩展框宽不足图像宽的 20% 或高不足图像高的 15% 时跳过；仍可能受原来的错误肤色范围影响。
2. 在扩展框高度的 12%–65% 范围寻找眼部，直接读取原图灰度，包含非肤色空隙。3×3 高斯平滑后做黑帽：`closing(gray) - gray`。核为椭圆，宽、高分别约为搜索来源框宽的 13%、7%，取奇数。核尺寸决定增强何种尺度的暗部，不代表人脸椭圆。
3. 搜索区内用 Otsu 阈值与最低响应 12 中较大者二值化，再做 1×3 横向闭运算。按相对宽高、面积及宽高比过滤连通块，保留眼睛暗部候选。
4. 枚举同一搜索框内的左右候选：间距为框宽的 18%–65%，连线倾角不超过 25°，面积小/大比例至少 0.30。
5. 原排序分数为：水平对齐 25%、面积相近 15%、间距接近框宽 36% 为 15%、黑帽响应 25%、候选周围肤色支持 20%。
6. 新增弱位置先验：只用训练集双眼标签，计算双眼质心的中点，再用图像宽高归一化。按图像等权统计中点均值和 x、y 标准差；标准差分别至少为图像宽的 18%、高的 15%，使偏好范围较宽。对于候选双眼中点，位置分为 `exp(-0.5 * ((dx/sigma_x)^2 + (dy/sigma_y)^2))`，只约束中点，不固定左右眼的位置或间距。
7. 最终分数为 `0.8 * 原分数 + 0.2 * 位置分`。分别按原分数、最终分数对同一批配对独立排序，跨框去重，保留前五个，第一位作为各自自动结果。位置先验不增加、删除暗部候选或配对，也不改变阈值、搜索范围和黑帽运算。权重、标准差下限在本轮运行前固定，不按验证结果搜索。

位置先验设置在 `config.json` 的 `position_prior` 中。`weight=0` 可恢复原分数排序；使用不含该字段的历史配置时不启用先验。实际训练图 ID、归一化均值、观测标准差与放宽后的标准差保存在输出 `settings.json`，页面也可展开查看。热图白色椭圆表示中点先验的一倍标准差范围，不是人脸椭圆。

所有数值是首轮启发式起步设置；没有做网格搜索或按验证标签调参。分数不是概率，产生配对也不代表识别正确。眉毛、眼镜框、发丝也会产生强暗部响应；侧脸、倾斜较大、肤色范围错误也可能失败。这里只定位眼睛暗部中心，不输出精确眼睛分割或虹膜中心。

## 如何解释指标

原始标签 4、5 分别为 `l_eye`、`r_eye`，各区域质心作为参考中心。按画面横坐标排序匹配双眼。只有双眼标签均存在且间距大于零的图像参与双眼误差统计。

`e = max(左眼定位距离, 右眼定位距离) / 标签双眼间距`。

- 自动首选命中：e ≤ 0.15 或 0.25 的图像数；没有配对也计为失败。
- 前五包含命中：只作候选排序诊断，不作为首选算法效果。
- 两眼附近均有候选：对两只标签眼分别找到最近的暗部候选，距离都不超过同一阈值。仅说明候选覆盖，不保证它们能通过配对约束或排到前五。

验证图标签不参与搜索框、黑帽运算、阈值、候选筛选和排序；训练标签仅用于统计一份全局中点先验。定位函数接收原图、肤色掩膜和全局先验，不接收本图标签。验证集本身也已用于此前 Lab4 讨论，结果是开发阶段观察，不是独立测试结论。

`eyes.py` 为定位算法；`build_gallery.py` 为训练先验统计、批量运行、事后测量与图册生成；`config.json` 保存参数。输出保留逐图 JSON/CSV、汇总、实际配置及本轮源码快照，包括原分、位置分、合计分和先验前后结果。实验文件与结果均单独放在 Lab4 新目录，没有修改 Lab3 核心实现及旧结果。

黑帽定义依据 [OpenCV 形态学文档](https://docs.opencv.org/4.x/d9/d61/tutorial_py_morphological_ops.html)。利用眼部线索约束人脸几何的研究背景可参见 [Hsu 等的 Face Detection in Color Images（ICIP 2001）](https://biometrics.cse.msu.edu/Publications/Face/HsuMottalebJain_FaceDetection_ICIP01.pdf)；本实验只采用简单黑帽与几何配对，并非复现其完整 EyeMap。
