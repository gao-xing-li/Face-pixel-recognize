# Lab4：双椭圆约束的形态学处理

这是 Lab4 最终实现，复用 `eye_check` 的双窗定位与 `eye_ellipse` 的几何先验，用内外椭圆限定对 Lab3 掩膜的修整范围。

## 复跑

按 [根 README](../../../README.md) 安装依赖后，在 Git 工作区的仓库根目录执行。

```powershell
python experiments/lab4/dual_ellipse_morph/build_gallery.py --output work/lab4_final
```

脚本读取 [配置](config.json)、`configs/skin_params.json` 和 `data/split_manifest.csv`，直接使用清单里的原图与原始标签。训练标签用于估计眼位和几何先验，固定在 32 张验证图上生成预测。可用 `--config` 更换双椭圆实验配置，每次须指定尚未存在的输出目录。工作区脚本调用 Git 记录结果来源。运行后打开输出目录的 `index.html`，汇总见 `summary.json`，逐图指标见 `per_image.csv`。

## 处理顺序

1. 对原图用 `k=1.25` 生成肤色掩膜，再取最大连通域并填孔，得到 Lab3 对照。定位优先采用面积小／大比例至少 `0.30` 的双眼配对。严格配对失败后采用配置中的放宽阈值，默认为 `0.20`。
2. 由双眼生成正中、向画面左偏和右偏三种基础椭圆，各自按 `0.82` 和 `1.20` 倍轴长生成内外椭圆。用外椭圆裁剪 Lab3 掩膜，保留与内椭圆重叠至少 24 像素的 8 连通块，取其内椭圆部分为核心种子。没有满足条件的连通块时，该候选记为不可用。
3. 内区使用 11×11 闭运算与填孔，过渡区使用 5×5 闭运算。种子占内椭圆面积的比例低于 `0.18` 时，使用 `k=2.00` 的放宽肤色掩膜在内区做 27×27 闭运算，再保留与种子重叠至少 24 像素的连通块并填孔。合并内区与过渡区后，保留与核心种子相交的部分，填孔并裁回外椭圆。
4. 可用候选按内外肤色支持率、前景保留比例和外边界占用率评分。侧向候选扣 `0.06` 分，同分优先选正中候选。无双眼配对或无可用候选时保留 Lab3 掩膜。

## 当前验证结果

- Lab3：F1 `0.7270`，IoU `0.5711`。
- 优化后：F1 `0.8289`，IoU `0.7079`。
- 32 张中 29 张提升、2 张轻微下降、1 张无双眼并保持 Lab3 结果。
- 低支持重建触发 4 张。31 张有双眼的图最终都选用正中候选，1 张回退 Lab3。
