# Lab4 一轮估计与修整

这是从肤色轮廓出发的早期试验。最终双眼引导方案见 [双椭圆形态学实验](../dual_ellipse_morph/README.md)。

从原始肤色阈值、小尺度闭运算、小尺度开运算三个版本产生椭圆候选，分别进行一次局部修整。复用相邻 `ellipse_check` 的候选与拟合模块，以及公共数据、填孔和评价函数。

## 运行

在仓库根目录执行：

```powershell
python experiments/lab4/estimate_refine/run.py --output work/lab4_estimate_refine
```

默认生成全部 32 张验证图。可通过 `--splits validation test train` 扩展查看，通过 `--config 路径` 调整参数，每次指定一个新输出目录。打开生成目录 `index.html` 即可离线查看。分享整个目录即可。

## 本轮操作

1. 固定肤色统计和 `k=1.25`，保留原始掩膜 M0。
2. 用 5×5 椭圆核分别做一次闭运算、开运算，与原始版本一起产生多个候选。
3. 从各版本候选轮廓拟合椭圆。所有肤色支持率回到 M0 计算。原图灰度的 3×3 形态学梯度用于描述边界证据。边界采样带是椭圆 5×5 膨胀减腐蚀，外邻带是 9×9 膨胀减 5×5 膨胀，使用方形邻域。
4. 缩放椭圆两轴得到内椭圆（0.8 倍）和外椭圆（1.15 倍）。Mlocal 为 M0 与外椭圆的交集，种子为 M0 与内椭圆的交集。
5. 对 Mlocal 做 9×9 椭圆核闭运算、填孔，限制在外椭圆内，得到修补建议。
6. 内椭圆接受修补建议，内外椭圆之间保留 Mlocal，随后保留与内部种子相交的连通块，可保留多块。

核尺寸与缩放比例都是本轮起步参数，尚未经搜索验证。没有种子或椭圆不可用时记录状态，原始结果仍可查看。拟合和修整完成后，才读取真值计算指标。

开闭运算先在图像外补零，完成后裁回原图尺寸；填孔随后调用已有 `fill_holes`，以背景 4 连通定义内部孔洞。

## 页面与结果

- 可切换图像、候选来源、单块和组合。不同来源的连通块编号各自独立。
- 过程图展示候选、范围限制、种子、修补建议、内部接受修补、种子关联及增删像素。
- 新增与删除图相对 M0，橙色为脸部、青色为非脸。逐候选另记录修整相对 Mlocal 的计数变化。
- `records.json` 保存组成块、实际拟合点、椭圆、支持描述和各阶段指标。`per_candidate.csv` 保存主要测量，`summary.json` 保存配对汇总。
- 汇总每张图每个来源只取面积最大的保留单块，四阶段在修整成功的同一批图上评价，注明有效图数。该参照便于观察简单起点；全部候选保留供讨论，未按真值选最优。
- 页面中梯度和分区肤色支持仅作描述，当前尚未据此实现自动候选排序。强边缘和高肤色支持也可能来自背景。
