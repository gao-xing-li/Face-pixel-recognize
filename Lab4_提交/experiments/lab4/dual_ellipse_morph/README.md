# Lab4：双椭圆约束的形态学处理

本实验建立在 `eye_ellipse` 之上，目标不是用椭圆直接替代人脸轮廓，而是限制形态学操作的范围。

## 处理顺序

1. 正常情况下仍使用双眼面积比例 `0.30`；只有严格配对完全失败时，才回退到 `0.20`，面积差仍参与配对评分。
2. 根据双眼生成正中、向画面左侧偏移、向画面右侧偏移三种基础椭圆。
3. 每种基础椭圆再生成内椭圆和外椭圆：内椭圆作为高可信种子区，外椭圆作为禁止越过的边界。
4. 先取得 Lab3 的“最大连通域后填孔”结果，再在其基础上修整。内椭圆使用较强闭运算与补洞；内外椭圆之间只使用较弱闭运算；外椭圆之外不允许新增像素。
5. 候选选择只使用肤色支持率、保留连通域比例和外边界接触情况，不使用当前验证图标签。
6. 侧向候选只有在图像评分明显高于正中候选时才会被采用；没有双眼配对时直接保留 Lab3 结果，不强行构造高置信度椭圆。
7. 如果内椭圆中的 Lab3 像素占比低于 `0.18`，说明原始肤色结果过于稀疏。此时额外生成 `k=2.00` 的放宽肤色区域，用 27 像素椭圆核连接碎片，只保留与原高可信核心相连且位于内椭圆中的部分。该分支不会直接把整个椭圆作为最终结果。

## 当前验证结果

- Lab3：F1 `0.7270`，IoU `0.5711`。
- 优化后：F1 `0.8289`，IoU `0.7079`。
- 32 张中 29 张提升、2 张轻微下降、1 张无双眼并保持 Lab3 结果。
- 低支持重建触发 4 张。侧向椭圆仍生成用于分析，但当前门槛下没有图像在缺少明确优势时发生偏移。
