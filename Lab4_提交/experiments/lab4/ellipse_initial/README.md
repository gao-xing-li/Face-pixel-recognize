# Lab4 椭圆候选检查

本实验从颜色阈值结果估计多个椭圆，观察人脸碎片和错误背景对椭圆定位的影响。

## 文件与运行

- `ellipse.py` 负责连通块、近邻组合、轮廓采样和拟合，只接收图像信息。
- `build_gallery.py` 复用现有数据、颜色检测和评价函数，生成离线图册。
- `gallery.html` 是图册模板。`config.json` 保存起步参数。
- 结果放在项目 `results/lab4_ellipse_check_20261108/`，与此前两套图册分别保存。

在仓库根目录执行：

```powershell
python experiments/lab4/ellipse_check/build_gallery.py --output results/lab4_ellipse_check_20261108
```

只生成验证集时添加 `--splits validation`。使用不同配置时添加 `--config 路径`，并指定新的输出目录。

双击生成目录的 `index.html` 即可离线浏览。分享时复制整个生成目录。可选择图像与候选、查看实际拟合点和椭圆。候选 JSON、CSV、运行配置及本次生成程序快照随结果保存。重新运行仍需仓库代码和数据。

## 本轮起步参数

沿用已有肤色统计及 `k=1.25`。以下参数是实现时选择的起步设置，尚未经选参验证。

| 参数 | 默认值 | 含义 |
| --- | --- | --- |
| min_component_area | 128 像素 | 达到下限的每个 8 连通块均产生单块候选 |
| max_box_gap | 32 像素 | 两个块外接框的最小欧氏间距上限 |
| max_chroma_distance | 12 | 两块平均 Cr/Cb 的欧氏距离上限 |
| neighbors_per_component | 2 | 每块从符合条件的近邻中，按间距、颜色距离选择最多两个 |
| max_points_per_contour | 256 | 每条外轮廓按轮廓索引等间隔采样的最多点数 |
| inner_scale | 0.6 | 中心椭圆两轴均缩到原轴的 60% |

每块与一个或两个近邻产生双块、三块组合，相同组成的候选去重。组合掩膜是组成块的并集，块间空隙仍保留。全部单块及组合都供查看，不从真值挑选赢家。

起步实现直接拟合各组成块的外轮廓点，裂缝边和错误背景也可能进入拟合。两轴为完整直径，长轴在前，角度沿图像坐标 x 轴计算。几何描述量包括内部肤色支持、中心与外围支持、候选被椭圆覆盖的比例、轴比及是否触边。触边和轴比异常供查看，不据此自动删除候选。

## 结果口径

候选构造和拟合先完成，随后才读真值做事后测量。图册中的 Precision、Recall、F1、IoU 来自实心椭圆区域，反映粗定位形状，不能直接当作新分割算法的提升结果。

默认展示最大保留单块的拟合椭圆，汇总表也只把它作为简单参照，注明有效图数。组合候选可以手动切换。颜色支持率由未填孔的原始肤色掩膜计算。高支持率也可能来自肤色相近的背景。

训练集作描述，原测试集作开发后检查，验证集是默认查看入口。本轮没有把椭圆应用到原有预测的裁剪或补全。
