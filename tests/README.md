# 共用检查

main 先保留公共检查目录。C 开发分支已提供基于 unittest 的手算、边界和批量评价检查，在其 README 的安装步骤完成后运行：

```text
python -m unittest discover -s tests -v
```

共用接口至少核对：混淆计数与正类方向、忽略区域、未定义指标、多图汇总、稳定 ID 配对、尺寸一致、划分重叠及异常处理。B 与 C 使用同一手算样例对齐口径。正式数据与算法接入后，由对应负责人补充必要的运行核查。

完整 C 测试集现有 51 项，包含 Boundary IoU 的手算边界、忽略区域及配对重采样检查。先安装 `python -m pip install -e ".[analysis]"`，确保补充指标所需的 OpenCV 可用。图像排版通过实际输出的视觉核查验证，正式预测与已有像素指标保持不变。
