# Fixed-prediction visual and supplementary assessment

All 32 test inputs, truth masks and saved predictions were verified against the original independent run. Pixel metrics are unchanged. The new boundary, paired-image Bootstrap and brightness-group results are post-hoc descriptions, not a new independent benchmark.

Boundary IoU: 2% image diagonal (14 px on 512x512), unweighted mean over defined images. Bootstrap: paired whole-image resampling, 10000 repeats, seed 42, percentile 95% intervals. Brightness: mean Y inside valid face ground truth, sorted into 11/11/10 groups; not a verified illumination condition or demographic label.

51 C checks passed. All 32 transparent exports preserve original RGB and use the exact B prediction as alpha. Report PNG/SVG and all sample boards are in the visualization download, generated by face-pixel-visualize.
