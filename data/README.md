# 已选图像与像素标签

本目录记录成员 A 人工主观筛选的 Face_segment 样本池，原图和标签位于 raw/face_segment/。原图和标签按原文件名一一配对；实际数量及校验信息以 `split_manifest.csv`、`part_a/metadata.json` 为准。

## 文件组织

```text
data/
├── raw/face_segment/images/   # 随分支提供的 162 张原图
├── raw/face_segment/labels/   # 随分支提供的 162 张原始多类别标签
├── split_manifest.csv        # 唯一划分；路径相对项目根目录
├── part_a/metadata.json       # 来源、标签、检查记录
├── part_a/split_report.json   # 划分与迁移记录
└── README.md
```

`split_manifest.csv` 中的 `image_path` 和 `label_path` 相对于项目根目录。`sample_id` 包含原集合及组号，以免不同组的同名文件发生混淆。匹配以清单或同名文件为准，不依赖目录遍历顺序。

## 来源与选样说明

- 图像来自 `Face_segment/test/real_image/2（人工筛选副本）`。
- 对应原图目录为 `Face_segment/test/real_image/2`。
- 标签来自 `Face_segment/test/real_label/2`。
- Face_segment 是 FedST 作者整理的 CelebAMask-HQ 子集：[FedST](https://github.com/YoferChen/FedST)、[CelebAMask-HQ](https://github.com/switchablenorms/CelebAMask-HQ)。使用与分享沿用原数据条款。
- 本次由实验者依据人物外观主观筛选样本。该筛选不属于数据集官方人群属性标注，存在主观性；目录组号 `2` 不作为已核实的人群标签，实验结论限于所选样本。
- 仅复制选中的 `real_image` 与对应 `real_label`，不使用 `fake_image`。

当前 162 对样本均筛选自 Face_segment 原始 `test`，没有使用原始 `train`；本实验的训练／验证／测试归属是对此子集重新划分的结果。原始 `train` 留有样本，可在实际需要时进一步筛选补充。实验者查看后反馈其中部分图像含敏感元素，人工筛查难度更大，目前不扩充，保留现有样本与划分。此项记录基于实验者反馈，未对原始 `train` 另做程序或逐图核查。

## 划分状态

已按约 6∶2∶2 划分：`train` 98 张、`val` 32 张、`test` 32 张，**实验者反馈无明显问题，划分人工检查通过**。先按样本 ID 排序，再使用 `random.Random(42).shuffle` 打乱，依次分配 98、32、32 张；最终名单以 `split_manifest.csv` 为准。`source_split=test` 仅记录下载包来源，不是本实验的集合归属。

划分前使用 64 位 dHash、汉明距离 ≤ 8 筛出 35 对相似候选，助手查看对照图后未发现明显同照片裁剪或缩放项，未建立相关照片分组。本次实际按图像随机划分；人物身份未核验，近重复筛查不保证穷尽。没有根据分割结果挑选种子或重划分。

按集合检查页面（本地生成的 `results/split_review/index.html`）提供三个集合的缩略图和原图—标签对照入口，[划分记录](part_a/split_report.json)保存方法与候选列表。原图和标签不移动、不复制到多个集合目录，以清单区分归属。

最初导入 163 对文件。`00583.png` 与 `00584.png` 的原图 SHA-256 完全相同，但两份标签内容不同。2026-10-29，实验者决定保留 `00583.png` 及其标签，排除 `00584.png` 及其标签。当前项目保留 **162 对文件，图像文件哈希均不同**；这不代表已完成近重复或人物身份检查，也不表示已判定保留的标签质量更高。

下载目录中的源文件保持不变。导入脚本记录该排除决定，重新运行不会将 `00584.png` 导入；元数据保留来源选样数量和排除原因。

## 标签含义

标签是单通道类别编号，不是 0/255 二值掩膜。编号较小，直接用图片查看器显示时接近黑色。读取后必须按类别取集合，不能用 `label > 0` 直接当成肤色或脸部真值。

| 编号 | 类别 | 编号 | 类别 |
| --- | --- | --- | --- |
| 0 | 背景 | 10 | 口腔内部 |
| 1 | 脸部皮肤 | 11 | 上唇 |
| 2 | 鼻子 | 12 | 下唇 |
| 3 | 眼镜 | 13 | 头发 |
| 4 | 左眼 | 14 | 帽子 |
| 5 | 右眼 | 15 | 耳饰 |
| 6 | 左眉 | 16 | 项链 |
| 7 | 右眉 | 17 | 脖子 |
| 8 | 左耳 | 18 | 衣服 |
| 9 | 右耳 | | |

2026-10-29 已确定：**肤色建模使用 `{1, 2}`，即 `skin` 和 `nose`**。仅这些标签位置的原图像素参与肤色统计，其余类别不参与。已完成 98 张训练图的全部有效像素 Cr/Cb 统计，使用原图、不做颜色增强、按像素等权。

脸部评价正类已确定为 `{1, 2, 4, 5, 6, 7, 10, 11, 12}`；忽略区域为 `{3}`（眼镜）；负类为 `{0, 8, 9, 13, 14, 15, 16, 17, 18}`。眼镜不计入 TP、FP、TN、FN 及所有指标分母，预测为任意类别均不加分也不扣分。分割与后续填孔仍处理整张图，不能借助真值眼镜标签指导推理。当前保留原始多类别标签，未生成派生二值标签或评价程序。
