# Part A 统计结果初步分析

日期：2026-10-29。本文解释当前训练集肤色统计，供报告撰写与 B 部分算法设计参考。数值来自已生成的参数、频数和逐图计数，不包含验证集选参或测试集评价。

## 1. 统计对象与计算口径

本次使用固定划分中的 **98 张训练图像**，从原始标签中选取 `1 skin`（脸部皮肤）和 `2 nose`（鼻子）对应的原图像素。皮肤像素为 5,838,561 个，鼻子像素为 548,991 个，合计 **6,387,552 个**。验证集和测试集图像没有参与参数计算。

原图保持原尺寸与颜色，不做白平衡、亮度调整或其他增强。图像按 8 位 BGR 读取，经 OpenCV `COLOR_BGR2YCrCb` 转换，输出顺序为 Y、Cr、Cb；本次仅统计 Cr、Cb，数值范围均为 0–255。

所有被选像素等权参与，不进行随机采样，也不先计算各图均值再平均。因此，本结果描述的是“训练集中所有选中肤色像素的总体分布”，脸部取样面积较大的图像会贡献更多权重。

正式参数见 [skin_params.json](../configs/skin_params.json)，逐图贡献见 [per_image_counts.csv](../results/skin_statistics/per_image_counts.csv)。

## 2. 均值和标准差说明了什么

| 通道 | 均值 | 总体方差 | 标准差 |
| --- | ---: | ---: | ---: |
| Cr | 151.14949561 | 87.88095189 | 9.37448409 |
| Cb | 109.11018055 | 89.93800609 | 9.48356505 |

均值表示这些训练肤色像素在相应通道上的平均位置。标准差反映像素在均值附近的离散程度：两通道的标准差都约为 9.4 个编码值，说明当前样本在两个通道上的总体离散尺度相近。这不表示两通道具有相同的分类能力，因为目前没有统计非肤色像素与肤色的重叠情况。

本次使用总体方差，即将平方偏差之和除以全部有效像素数 `N`，对应 `ddof=0`。方差用于描述离散程度，标准差与通道值具有相同量纲；如果后续使用均值加减若干倍离散尺度构造范围，应使用标准差，而非直接使用方差。

这组参数是当前数据、标签和颜色处理方式下的统计结果。它们不等同于普遍适用的亚洲人脸肤色范围，也不能仅凭数值大小判定分割效果。

## 3. 单通道分布：存在集中区域，也存在尾部

![训练肤色像素的 Cr、Cb 分布](../results/skin_statistics/channel_distributions.png)

图中横轴为通道编码值，纵轴为该取值占全部选中肤色像素的比例。可以看到，两通道均有明显集中区域，主要像素位于均值附近，远离中心后频数整体降低。这说明使用集中位置与离散程度概括训练肤色分布具有一定依据。

同时，图中仍存在低频尾部，局部频数也有起伏。单个均值和标准差会压缩这些细节，不能完整表达全部像素的分布形状。本次没有进行正态性检验，不能仅凭主峰形状就认为分布严格服从正态分布，也不应直接套用正态分布的理论覆盖率。

图中的实线是均值，虚线是均值 ± 1 个标准差，作用是帮助观察离散尺度。虚线没有被确定为实际分割边界。

## 4. 联合分布：Cr 与 Cb 有较强负相关

![训练肤色像素的 Cr/Cb 联合分布](../results/skin_statistics/joint_distribution.png)

联合图横轴为 Cb、纵轴为 Cr，颜色表示该整数取值组合的像素数。颜色采用对数刻度，以便同时观察高频集中区和低频区域；这一显示方式没有改变像素权重。

可以看到，高频区域整体呈倾斜形状。根据联合频数计算，两通道的总体协方差约为 **−67.9545**，相关系数约为 **−0.7644**，表明在当前训练肤色像素中，Cr 较大的位置往往对应较小的 Cb，反之亦然。该结果是合并像素层面的统计关系，不代表每张图像内部都有相同程度的相关性，也不说明因果关系。

这一现象对 B 的意义是：分别查看 Cr 和 Cb 的范围，会丢失一部分通道之间的关系。若后续分别设置上下限并要求两个通道同时满足，得到的是轴对齐矩形；它可能包含联合图中较低频的角落，也可能漏掉沿倾斜方向延伸的部分肤色。

这为解释简单阈值方法的限制提供了依据，但尚不足以证明必须换用其他模型。实际采用何种判别规则，应由 B 结合实现成本和验证集效果决定。

联合图中还存在离开主集中区的低频延伸。当前仅进行了总体统计，没有逐图追踪这些像素的来源，不能直接归因为光照、化妆、图像处理或标注误差中的某一种，也未据此删除像素或样本。

## 5. 不同图像对统计的贡献

| 项目 | 有效肤色像素数 |
| --- | ---: |
| 单图最少 | 30,666 |
| 单图中位数 | 65,139.5 |
| 单图最多 | 92,562 |

贡献最少和最多的图像分别占总取样量约 **0.48%** 和 **1.45%**；若每张图像等权，每张的权重应约为 1.02%。可以看到，当前确实存在面积权重差异，最大单图贡献约为最小单图的 3 倍，但没有某一张图单独占据很大比例的情况。

这个结果说明按像素汇总的权重差异有多大，不能证明各种光照、姿态或拍摄条件都已平衡。多张具有相似条件的图像仍可能共同影响总体分布。当前继续保留已确定的按像素等权口径，不根据这些统计另行修改权重。

## 6. 范围覆盖率：用于理解分布，不作为选参结论

为说明统计范围宽窄与肤色覆盖的关系，以下仅对已有联合频数作描述性计算。假设同时满足：

\[
|Cr-\mu_{Cr}|\leq k\sigma_{Cr},\qquad
|Cb-\mu_{Cb}|\leq k\sigma_{Cb}
\]

则位于该矩形内的训练肤色像素比例为：

| 示例系数 k | 范围内训练肤色像素数 | 占全部训练肤色像素 |
| --- | ---: | ---: |
| 1 | 3,779,776 | 59.17% |
| 2 | 5,867,435 | 91.86% |
| 3 | 6,346,575 | 99.36% |

随着范围扩大，覆盖的训练肤色像素增加。该表统计的是已知皮肤与鼻子像素，没有加入背景或其他负类，所以无法回答扩大范围会多检出多少头发、衣服或背景像素。

这些比例不是最终脸部区域的 Recall、F1 或 IoU：最终脸部正类还包括眼睛、眉毛和嘴部，而这张表的分母只有训练皮肤与鼻子像素；它也没有涉及验证集或测试集。

因此，该表不能用于断言某个 k 最佳，也没有将矩形规则或 `k=2` 确定为 A 的正式交付方案。B 可以将其作为理解统计尺度的参考，再通过验证集决定规则与参数。

## 7. 数据与评价目标的边界

本次数据由实验者主观外观筛选得到，缺少官方人群属性标签；162 张图像中仅 98 张用于肤色统计。六百多万个像素来自有限数量的照片，不能视为同等数量的独立人物或独立场景。像素数较多有利于描述当前图像中的颜色分布，并不自动意味着覆盖了广泛的人群和成像条件。

此外，目前只统计了肤色正样本，还没有分析负类与肤色的重叠，也未进行分割实验。因此，可以说明颜色集中性和通道关系，但还不能证明仅靠颜色就能可靠区分脸部与背景。

肤色统计与最终脸部评价的范围已明确区分：统计使用 `{1, 2}`；脸部评价正类为 `{1, 2, 4, 5, 6, 7, 10, 11, 12}`；眼镜 `{3}` 不计入任何评价计数，其余为负类。眼睛、嘴唇等没有参与颜色建模，最终是否能完整保留这些区域，需要 B 的分割流程验证。

如果 B 沿用这些参数，读图顺序、转换方式、像素范围和颜色预处理应与当前统计一致。若改变这些条件，应协调重新计算相应参数。判别规则、阈值系数与辅助处理由 B 选择并验证。

## 8. 证据与当前结论

正式统计已通过小数组数值测试和独立读图计算复核，98 个训练 ID、各级计数和输入哈希一致；独立计算的两通道均值、方差、标准差与保存参数完全一致。证据见 [verification.json](../results/skin_statistics/verification.json)。这证明当前实现与约定的统计口径一致，算法效果仍需后续实验检验。

本分析使用的相关性、逐图贡献摘要和示例覆盖率保存于 [preliminary_analysis_metrics.json](../results/skin_statistics/preliminary_analysis_metrics.json)，并附来源文件哈希。联合频数的数组顺序为 `[Cr, Cb]`；相关性按像素频数加权计算，覆盖率为矩形内频数之和除以总频数，均未重新抽样。

目前可以形成的初步判断是：当前训练肤色在 Cr/Cb 平面具有明显集中区域，两个通道存在较强负相关，均值和标准差可作为后续颜色判别的统计依据。A 已提供数据与分布解释；判别形式、阈值以及完整脸部区域的恢复效果，交由 B 通过验证确定。
