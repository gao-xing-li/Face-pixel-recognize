## 4. 已有建模方向与期望输出

[分工文档](../分工文档.md)已有的优先路线是 **YCbCr 颜色空间下的肤色均值、方差统计与颜色阈值分割**。本人已确定：原图不做颜色增强，转换到 YCrCb 后使用 Cr、Cb，汇总训练集全部有效肤色像素，按像素等权计算均值和标准差。脸部面积较大的图像贡献更多像素，不采用逐图等权或随机采样。

本人期望最终能得到**包含眼睛、嘴巴等内部区域的完整脸部区域**，同时考虑当前颜色阈值方法的实现难度。这是期望输出，尚未落实为已经确定并验证的完整脸部区域分割方案。原分工文档中的基础输出仍是肤色掩膜，两者不能直接视为同一结果。

已核查所选 Face_segment 的标签包含 `0–18` 共 19 个类别，除皮肤外，还区分鼻子、眼睛、眉毛、嘴部、嘴唇等。因此，当前数据并非只有脸部皮肤的二值标签。

2026-10-29，本人决定：**肤色建模取样采用 `1 skin` 和 `2 nose`**。仅提取这两个类别位置对应的原图颜色，其他类别不纳入肤色统计。统计程序已实现；原始多类别标签保持不变，尚未保存派生二值标签。

随后本人确定：脸部评价正类为皮肤、鼻子、双眼、双眉、口腔和上下唇，即 `{1, 2, 4, 5, 6, 7, 10, 11, 12}`；眼镜 `{3}` 为忽略区域；其余类别 `{0, 8, 9, 13, 14, 15, 16, 17, 18}` 为负类。

眼镜不参与肤色参数统计，也不计入评价的 TP、FP、TN、FN 及指标分母，既不加分也不扣分。推理与后续填孔正常处理整张图，不使用真值标签指导补全。指标评价非眼镜区域的分割质量，不证明眼镜区域补全效果。这里只确定口径，未新增填孔或评价实现。

## 6. 肤色统计实现设计

本节在编写统计程序前记录，范围是 A 的肤色取样、统计参数和分布展示，不包含 B 的选参、分割与填孔实现。

### 6.1 输入与颜色约定

- 以 `data/split_manifest.csv` 的正式划分为唯一入口，只读取 `split=train` 的 98 对图像与标签。验证、测试只计清单条目，不读取其图像来参与统计。
- 运行前核对划分已人工通过、清单哈希与记录一致、样本 ID 不重复；训练图像及标签核对文件哈希、尺寸、模式与合法类别。任一训练图没有肤色像素则报错，不静默跳过。
- 使用 OpenCV 读取 8 位 BGR 图像并调用 `cv2.COLOR_BGR2YCrCb`；输出顺序为 Y、Cr、Cb，使用通道 1（Cr）、2（Cb），数值范围 0–255。标签按单通道整数类别读取。
- 不缩放、不增强、不做白平衡、平滑或标签腐蚀。取样掩膜为 `(label == 1) | (label == 2)`，眼镜及其他类别不参与。原始图像与标签不修改，不额外生成正式二值标签。

### 6.2 汇总与数值口径

- 每张训练图的全部有效像素均参与，所有像素权重为 1；不平均各图均值，不进行随机抽样。
- 逐图累计 Cr、Cb 各 256 个整数取值的频数，以及 256 × 256 的 Cr/Cb 联合频数。使用 `int64` 计数，避免保存所有图像的像素数组；该方式对 8 位整数数据与直接合并全部像素等价。
- 对任一通道，设取值为 `v` 的像素数为 `h[v]`，总像素数为 `N`。计算 `mean = sum(v*h[v])/N`，`variance = sum(h[v]*(v-mean)^2)/N`，`std = sqrt(variance)`。数值计算使用 `float64`。
- 采用总体方差，即 `ddof=0`、分母为 `N`，描述本次全部训练肤色像素的分布；同时保存方差与标准差，阈值公式使用标准差。
- 逐图记录皮肤像素数、鼻子像素数、总取样数、占本图比例及占总体统计权重，便于核查实际贡献。

### 6.3 程序与输出

- 入口：[compute_skin_statistics.py](../tools/compute_skin_statistics.py)，从项目根目录运行；本次使用独立 `.venv` 中的 Python 3.13.7、NumPy、OpenCV、Pillow、Matplotlib，依赖版本记录在参数文件及 [requirements-part-a.txt](../requirements-part-a.txt)。
- `configs/skin_params.json`：Cr/Cb 均值、方差、标准差、有效像素数、通道与读图约定、标签范围、加权方式、训练样本 ID、清单及训练内容指纹、依赖版本。
- `results/skin_statistics/per_image_counts.csv`：训练图逐图计数和统计权重。
- `results/skin_statistics/histograms.npz`：两通道与联合频数，作为可复核的分布数据。
- `results/skin_statistics/channel_distributions.png`：Cr、Cb 的像素频率分布，标示均值及均值 ± 1 个标准差，后者仅为分布参考线，不代表选定阈值。
- `results/skin_statistics/joint_distribution.png`：横轴 Cb、纵轴 Cr 的联合频数图，颜色使用对数计数便于观察低频区域，不改变统计权重。
- `results/skin_statistics/README.md`：本次运行摘要、参数、图表入口及统计口径。输出只描述训练数据，不报告未经执行的分割效果。
