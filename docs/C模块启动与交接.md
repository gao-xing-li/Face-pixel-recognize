4. 手算样例及自动检查：混合错误、全正确、全漏检、全误检、无正类、忽略区域、全忽略、逐图与总体汇总差异。

## C 后续顺序

1. 先用模拟小掩膜完成评价开发，运行 README 中的测试和 demo。
2. 已接入 A 固定版本并核对全部样本的标签、配对、尺寸、文件哈希及统计来源；身份/近重复限制继续按 A 的记录保留。
3. 与 B 核对同一验证样例上的计数和指标，基础版先接通。
4. 收到固定配置后运行独立测试，保存预测、统计、输入哈希与配置记录。正式结果必须有可追溯代码、模型参数及划分，不能只拿一个配置名称代替实际配置。
5. 整理成功、误检、漏检案例，并据实际证据分析光照、背景、皮肤范围或遮挡等因素。报告同时保留总体和逐图结果，标明无定义指标处理。
6. 收齐 A/B 章节与图表后整合，矛盾和缺失交由原作者修正。提交时间和邮箱按课程通知核对。
