# Lab4 操作方向与整体流程

更新日期：2026-11-08。本文作为 Lab4 当前进展与组员交接的总入口。先阅读下述已做实验与判断，再根据链接检查具体代码、逐图结果和历史设计。

## 当前做到哪里

为了让肤色区域能支持较可靠的人脸椭圆，先尝试了画椭圆前的简单开闭操作，随后又尝试用眼睛位置提供额外定位信息。目前有两套分别可运行、可查看的实验：

1. **弱预操作与椭圆检查**：原始肤色掩膜、5×5 闭运算、5×5 开运算三种输入，分别取面积前三个连通块，各自拟合并展示椭圆。
2. **眼睛定位**：从灰度黑帽响应寻找暗部候选并配对，依次比较无位置先验、双眼中点弱先验、两眼位置分别约束三版。

**眼睛定位尚未接入椭圆估计。** 目前没有确定如何由眼睛推算人脸椭圆中心、轴长与范围，也没有验证这条路线能否改善最终脸部分割。椭圆之后的修整当前暂停；曾经运行过的一轮完整“估计—修整”保留为历史结果，不能当成已经与最新眼睛方法接通的完整流程。

## 已做尝试与当前判断

| 尝试 | 原本希望解决什么 | 本轮观察与判断 |
| --- | --- | --- |
| 画椭圆前做轻量闭运算 | 让分散的脸部块先合并，使较大的候选充分包含人脸 | 本轮 5×5 闭运算没有很好地接上希望合并的脸部块；缺失或间隔较大的部分仍然断开，椭圆仍受碎片和背景干扰。 |
| 画椭圆前做轻量开运算 | 切断与背景的粘连，保留更像人脸的候选 | 对本来属于脸部边缘的细窄区域、连通块破坏较明显；去掉的并不都是背景，也会丢失有用的拟合轮廓。 |
| 无位置先验找眼睛 | 用双眼提供额外位置、方向线索，减少对肤色轮廓的依赖 | 容易选到眉毛、头发等暗部；验证集粗定位合格 13/32，单靠当前暗部与几何规则还不可靠。 |
| 双眼中点弱先验 | 给中心略偏上的配对少量加分，纠正明显偏离位置的结果 | 只改排序，合格数变为 15/32，改善有限，眉眼混淆等问题仍在。 |
| 两眼分别统计并加强约束 | 分别限制左右眼实际查找范围，并加强位置排序 | 合格数提高到 28/32，但明显依赖本数据集眼睛位置高度集中的特点，不能等同于通用眼睛识别能力。 |

开闭操作的判断来自当前设置下的逐图检查与小组讨论，尚未统计“连接成功率”“误删脸部边缘比例”等专项指标，也未系统搜索核大小。因此结论是**当前简单预操作没有达到期望，不能据此把后续椭圆当成可靠结果**，而不是断言所有形态学方法都无效。

从机制上看，闭运算按局部形状连接邻近前景，不知道哪些是脸部碎片；开运算也不知道细窄区域属于背景还是脸部。继续增大核是否有收益、会不会接入更多背景或丢失更多人脸，需要另做对照，当前没有定下新方案。

### 眼睛结果应怎样解释

32 张验证图均有双眼标签。以标签眼睛区域质心作参考，`e = 两眼中较大的定位距离 / 标签双眼间距`；无配对计为失败。

| 方法 | e ≤ 0.15 | e ≤ 0.25 |
| --- | ---: | ---: |
| 无先验 | 13/32 | 13/32 |
| 双眼中点弱先验 | 15/32 | 15/32 |
| 两眼分别约束搜索 | 26/32 | 28/32 |
| 仅输出训练集双眼均值，不看图像（诊断对照） | 32/32 | 32/32 |

位置统计只使用训练集 98 张中有双眼标签的 97 张，验证图标签只作事后评价。最新版分别在两眼统计中心附近开搜索窗，位置分占 65%，图像分占 35%；窗内没有合适图像候选或配对时不会填入统计均值。

因此，小组目前的判断可表述为：**这套简单眼睛定位方法在使用当前数据的位置先验后才比较准确；提升很大程度受益于数据构图一致，尚不能归因于图像识别本身变得很强。** 第三版还同时改了搜索范围和排序，不能只把改善归因于提高权重。验证集已参与多轮观察，这些是开发阶段结果，尚未独立验证新图像或最终人脸分割效果。

典型例子及具体失败原因见 [眼睛定位实验记录](眼睛定位实验.md)。其中 00590 从误选双眉变为双眼；00690 则从上一版正确变为无配对，原因是两眼候选面积比例未通过原有过滤规则。不要只展示成功图。

## 历史讨论与备选流程

以下保留此前形成的方向、流程框架和研究线索。涉及“拟”“待选择”的内容均是历史备选，不表示已实现或已批准为下一步；当前状态以本文上半部分为准。

### 小组原始方向

小组目前确定了以下研究方向。

1. 利用人脸轮廓近似椭圆的先验，帮助定位、判断或修整人脸区域。
2. 改进实验三中颜色阈值后直接选择最大连通块的步骤，分别尝试两条路线。
   - 合并路线：尽量使断开的人脸像素组成更连贯的区域，再选择人脸候选。
   - 分离路线：尽量将与脸部粘连的背景、头发等区域分开，再选择人脸候选。

实验需要说明尝试理由、预期变化、实际结果及原因。不同图像上的改善和副作用都属于需要分析的结果。

## 现有流程与改进动机

当前代码中的 `original` 方案为：

```text
原图 → Cr/Cb 颜色阈值（k=1.25）→ 最大 8 连通块 → 填孔 → 输出
```

当前 `final` 方案在最大连通块后使用 41×41 椭圆核膨胀、填孔和腐蚀。它是已有补全方案，可作为后续对照。

前期逐图检查发现，最大连通块筛选会删除一些断开的人脸碎片，也可能保留较大的错误区域。后续拟将人脸候选的最终选择往后移，先给连接或分离操作保留足够的输入信息。

现有实现见 [detection.py](../../src/face_pixel/detection.py)，已有分阶段实验见 [最大连通域对照说明](../../experiments/lab4/connected_components/README.md)。

## 拟探索的整体操作顺序

以下是当前讨论形成的流程框架。具体操作、参数以及椭圆介入位置仍需通过实验确定。

```text
颜色阈值分割
    ↓
保留原始掩膜，进行轻量预操作
    ↓
分别从原始、轻量连接、轻量分离的结果产生候选
    ↓
形成多个单块及近邻组合候选
    ↓
估计椭圆，检查内部肤色分布与原图边界支持
    ↓
对候选椭圆分别进行一轮局部修整
    ↓
内部修补、边界带保留图像证据、外围抑制
    ↓
对照原结果，分析候选定位与修整效果
```

两条首轮路线的拟定顺序如下。

| 路线 | 初步流程 | 要观察的现象 |
| --- | --- | --- |
| 合并 | 阈值 → 小尺度连接或近邻区域组合 → 候选判断 → 填孔 | 脸部碎片是否被保留，背景是否也被接入 |
| 分离 | 阈值 → 小尺度断开粘连 → 候选判断 → 填孔 | 背景是否被分开，脸部是否被误删或切断 |

闭运算、局部肤色密度修整和区域组合是合并路线的候选方法。腐蚀、开运算及标记控制分水岭是分离路线的研究线索。方法及参数尚待选择。

“组合候选”可以先把几个区域作为一组进行判断，组合后的实际连接路径和像素补充另行设计。候选框或候选分组的合并，本身不会自动给出新的二值脸部掩膜。

## 椭圆探索的开展顺序

第一轮椭圆检查已从原始肤色掩膜的单个区域及近邻组合产生候选并完成可视化，设计与实现记录见 [椭圆检查设计](椭圆检查设计.md)。已观察到背景轮廓影响拟合、局部碎片产生过小椭圆等情况，后续将加入弱预操作和原图边界支持，再观察局部修整能否有效。

椭圆在最终流程中的位置，根据该检查的结果调整。

| 检查结果 | 后续流程选择 |
| --- | --- |
| 原始肤色区域已能支持可靠椭圆 | 提前估计粗椭圆，再尝试用其约束连接、分离或补全 |
| 原始区域太碎，连接后定位才较合理 | 先连接或组合，再估计椭圆 |
| 背景粘连影响定位，分离后才较合理 | 先分离，再估计椭圆 |
| 椭圆经常跟随错误背景或只包住局部碎片 | 回到候选产生与轮廓点选择，分析失败原因 |

当前拟先尝试一次如下流程：

```text
阈值 → 弱预操作 → 多个候选 → 粗椭圆
                       ↓
          附近的连接或分离处理
                       ↓
          输出一轮修整结果并分析
```

## 仍需实验判断的环节

- 椭圆用于候选判断、限制处理范围，还是进一步参与输出掩膜的裁剪或补全。
- 最大面积继续作为选择依据之一，还是结合椭圆、肤色密度等信息调整候选选择规则。
- 合并与分离是否组合，以及组合时的顺序。闭运算可能重新接上开运算切断的连接，开运算也可能破坏闭运算形成的连接。
- 填孔暂放在候选选择之后，以便观察其对目标候选的作用；如需提前填孔，应单独记录其对候选形状和选择的影响。

当前沿用已有颜色统计、标签口径和数据划分。具体实验记录应保留操作顺序、参数、候选来源和逐图变化，便于回到假设和实现进行调整。全自动候选排序、分水岭和反复更新椭圆仍属后续选择，需由首轮现象决定是否投入。
