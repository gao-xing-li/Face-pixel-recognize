# Lab4 后续优化过程记录

日期：2026-11-08

## 1. 当前基线

当前版本为“眼睛定位 + 双椭圆约束 + 分区形态学处理”。处理从 Lab3 的最大连通域填孔结果开始：内椭圆进行较强闭运算和填孔，内外椭圆之间进行较弱闭运算，外椭圆之外不增加像素。

验证集共 32 张，当前结果如下：

- Lab3：F1 = 0.7270，IoU = 0.5711。
- 当前 Lab4：F1 = 0.7977，IoU = 0.6635。
- 28 张提升，3 张下降，1 张不变。
- 29 张正常检测到双眼，2 张通过放宽条件找回，1 张未检测到双眼并回退 Lab3。

同时发现：只使用正中椭圆时 F1 = 0.7984，略高于当前自动选择正中/左移/右移椭圆的 F1 = 0.7977。这说明侧向候选本身有价值，但当前选择规则还不够稳定。

## 2. 本阶段目标

按以下顺序继续优化：

1. 提高侧向椭圆的启用门槛，减少不必要的偏移。
2. 检测“内椭圆中脸部像素过少”的情况，并尝试受椭圆限制的区域重建。
3. 评估单眼或无双眼时的低置信度后备方案。

所有方案仍遵守同一原则：验证标签只用于处理完成后的评价，不参与椭圆选择和最终预测。

## 3. 试验记录

### 试验 1：侧向椭圆选择规则

状态：保留。

计划：分析正中、左移和右移候选的图像分数差异，提高侧向候选相对正中候选的最低优势要求。先验证能否避免错误偏移，再决定是否保留。

初步诊断：当前共有 3 张图选择了侧向椭圆，它们相对正中候选的图像分数优势分别约为 0.043、0.055 和 0.055，但事后评价显示这 3 次偏移都没有超过正中候选。因此先将最低优势要求由 0.04 提高到 0.06，进行完整复跑。

结果：提高门槛后，31 张有双眼的图全部保留正中椭圆，1 张无双眼图继续回退 Lab3。全局 F1 从 0.7977 提高到 0.7984，IoU 从 0.6635 提高到 0.6645；平均单图 F1 增量从 0.0502 提高到 0.0508。提升不大，但避免了 3 次没有实际收益的侧向偏移，因此保留该修改。侧向候选仍生成并保留在图册中，后续如果获得更可靠的姿态证据，可以重新启用。

### 试验 2：脸部像素过少时的椭圆约束重建

状态：保留试验 2C 参数。

计划：先根据内椭圆中的已有像素占比识别低支持样本。正常样本继续使用原流程；低支持样本尝试从高可信核心像素进行受限扩张，扩张范围不超过内椭圆，并设置停止条件，避免直接填满整个椭圆。

试验 2A：将内椭圆支持率低于 0.18 的图像判为低支持样本，共触发 4 张。把肤色阈值范围由 `k=1.25` 放宽到 `k=1.55`，对放宽后的肤色区域做 15 像素闭运算，只保留与原高可信核心相连的部分。全局 F1 提高到 0.8124，IoU 提高到 0.6841；29 张提升、2 张下降、1 张不变。4 张低支持样本均有提升，其中原先退化最明显的 00548 从“比 Lab3 低 0.0269”变为“比 Lab3 高 0.0457”。

观察：该方案不是直接填满椭圆，重建结果仍由放宽后的肤色证据和原核心共同决定。00548、00562 仍存在较大缺失，因此继续测试稍宽的肤色范围和连接尺度。

试验 2B：把放宽范围提高到 `k=1.75`，连接核提高到 21。全局 F1 进一步提高到 0.8227，IoU 提高到 0.6987，平均单图 F1 比 Lab3 高 0.1055。00548、00562 和 00733 的缺失继续减少，00660 略有回落但仍比 Lab3 高 0.6113。继续做一次更强参数测试，用于判断何时开始出现过度填充。

试验 2C：使用 `k=2.00` 和 27 像素连接核。全局 F1 达到 0.8289，IoU 达到 0.7079，平均单图 F1 比 Lab3 高 0.1152。低支持样本继续改善，但重建结果已更接近内椭圆边界，开始出现把额头上方头发区域纳入结果的风险。因此再做一次更强的上界试验；如果收益停止或视觉误检明显增加，就回退到本次参数。

试验 2D：使用 `k=2.25` 和 33 像素连接核。全局 F1 提高到 0.8350，但 4 张低支持图的重建结果已经接近直接填满内椭圆，额头和头发附近误填风险明显增加。虽然验证指标更高，但方法开始退化为“椭圆代替分割结果”，与本实验原先确定的约束作用不符，也会过度依赖椭圆定位精度。因此不保留该参数，最终回退到试验 2C 的 `k=2.00` 和 27 像素连接核。

结论：保留低支持重建，最终参数为支持率阈值 0.18、放宽肤色系数 2.00、连接核 27。与最初 Lab4 相比，全局 F1 从 0.7977 提高到 0.8289，IoU 从 0.6635 提高到 0.7079；与 Lab3 相比，F1 提高约 10.19 个百分点。

### 试验 3：无双眼时是否强行估计椭圆

状态：不启用，保留安全回退。

验证集中唯一没有双眼配对的 00592，Lab3 F1 已达到 0.8696，明显高于验证集整体水平。如果在没有可靠眼睛尺度和方向的情况下，根据肤色块强行拟合椭圆，容易重新引入“背景最大块决定椭圆”的旧问题。因此当前方案仍直接保留 Lab3 结果。以后若增加单眼定位、鼻尖或人脸检测器等独立证据，再考虑低置信度椭圆。

## 4. 最终保留方案

1. 严格双眼配对失败时，才使用放宽面积比例的双眼配对；仍失败则回退 Lab3。
2. 正中椭圆作为默认，侧向候选必须比正中候选高至少 0.06 才能启用。
3. 普通样本沿用内区强闭运算、过渡区弱闭运算、外区禁止新增的处理。
4. 内椭圆支持率低于 0.18 时，使用放宽肤色证据进行受限重建，但不允许越过内椭圆，也不允许与原核心无关的区域进入结果。
5. 最终开发集结果：F1 = 0.8289，IoU = 0.7079；29 张提升、2 张轻微下降、1 张保持不变。

## 5. 报告撰写时需要说明的限制

- 当前参数经过验证集多轮观察，属于开发阶段结果，不应表述为独立测试集性能。
- 数据中的眼睛位置较集中，眼睛先验和椭圆先验可能无法直接推广到构图差异较大的照片。
- 低支持重建解决了原始肤色像素过少的问题，但放宽颜色范围后仍可能包含额头上方头发或相近颜色背景。
- 两张轻微下降样本的 F1 变化约为 -0.0019 和 -0.0010，说明外椭圆裁剪仍可能删去少量真实边缘。
