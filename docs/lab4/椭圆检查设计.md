# Lab4 椭圆检查初步设计

记录日期：2026-11-08。本文是代码实现前的设计记录。整体背景见 [操作方向与整体流程](操作方向与整体流程.md)。

当前精简版对原始、轻量闭运算、轻量开运算三种输入分别按面积取前三个连通块，各自拟合椭圆，先不展开区域组合或后续修整。已生成验证集 [前三块椭圆图册](../../results/lab4_ellipse_top3_20261108/index.html)，运行参数见 [实现说明](../../experiments/lab4/ellipse_check/README.md)。下文保留初始多候选设计及其历史实现记录。

本文保留从肤色轮廓直接拟合椭圆的早期路线。[估计—修整实验](估计—修整实现设计.md) 曾做过一轮完整修整，之后将该路线收缩到前三块可视化。最终流程已改用检测双眼生成内外椭圆，见 [交接总览](操作方向与整体流程.md)。

## 本轮弱开闭操作的观察结论

目的：在画椭圆前做少量连接或分离，让候选更充分地包含脸部、减少背景轮廓干扰。实际对照采用同一肤色阈值 k=1.25，对原始、5×5 椭圆核闭运算和开运算三种输入，各自按面积取前三个连通块分别拟合，不进行块组合。结果见 [逐图图册](../../results/lab4_ellipse_top3_20261108/index.html)。

- **闭运算未很好完成预期合并。** 希望连接的脸部块往往仍然分离，局部缺失未被补上；之后取大块或拟合椭圆时，脸部仍可能不完整。较小核的局部连接能力有限；增大核也可能连接背景，目前未系统验证更大核的收益。
- **开运算会损伤本来有用的脸部边缘。** 希望切开背景粘连，但细窄的人脸边缘和连通区域同样可能被削弱、断开或删除，使拟合轮廓进一步缺失。不能把被开运算去除的区域都视为背景。
- **当前判断**：本轮简单预操作效果有限，尚不足以保证可靠椭圆。椭圆是否拟合成功与是否定位到人脸是两件事；错误背景或局部碎片同样可能拟合出椭圆。

以上为当前参数下的逐图观察与小组判断，尚无专项的合并成功率、边缘误删比例或核大小系统对照，不将其推广为“开闭运算均无效”的一般结论。

随后尝试以眼睛提供位置线索，详情见 [眼睛定位实验](眼睛定位实验.md)。目前在较强的双眼位置先验下定位才较准确；尚无确定并实现的眼睛到人脸椭圆映射，不能将眼睛图册当成改进后的椭圆结果。

## 目标与实验问题

检查现有颜色分割结果能否支持一个位置、大小和方向大致正确的人脸椭圆，为后续候选选择及形态学约束提供依据。

首轮需要回答：

1. 肤色分割较完整时，椭圆是否贴近人脸，能否减少头发、脖子或背景的干扰。
2. 肤色分割碎裂时，单块或近邻组合能否支持整张脸的范围估计。
3. 椭圆跟随错误区域、偏移或过小时，问题来自候选缺失、轮廓污染，还是拟合方式。

“椭圆检查”先输出候选和拟合结果，检查它们的空间关系。让椭圆参与像素裁剪或补充，是在定位结果得到分析后的下一阶段。

## 输入与处理流程

使用现有原图、肤色均值和标准差，起步沿用 `k=1.25`。图像保持原尺寸。首轮优先查看验证集，再按分析需要查看其他划分并注明用途。

```text
原图
  ↓
颜色阈值掩膜
  ↓
保留多个连通区域
  ↓
构造候选（单块及少量近邻组合）
  ↓
提取候选轮廓点
  ↓
估计椭圆中心、轴长和角度
  ↓
记录支持情况并可视化检查
```

真值用于输出后的对照和测量。候选构造、拟合点选择、椭圆参数和自动排序均从原图或预测得到。

## 候选与轮廓点

### 单块候选

保留多个前景连通块，分别记录面积、外接框、位置和对应轮廓。单块候选可以检查哪些区域已经具有脸部形状，以及大块误检怎样影响拟合。

### 近邻组合候选

部分脸部可能分成额头、脸颊等几块，需要观察它们共同形成的候选。拟先研究空间接近程度，并结合原图颜色相似性决定哪些区域值得组合。

距离定义、相似性阈值、最多组合几块及是否去掉极小区域，均是待确定的实现细节。首轮以容易解释的少量组合为起点，保留组成区域的 ID，使结果可追溯。

### 拟合点

起步方案从候选掩膜提取外轮廓点。组合候选可汇集各组成区域的外轮廓点。需要保存或显示实际使用的点，才能检查拟合为何偏向某个区域。

轮廓中可能包含朝向裂缝的边、头发及背景边界，拟合会受其影响。如首轮出现明显偏移，再研究更可信的轮廓点选择、均匀采样或稳健拟合，并与起步方案比较。

## 椭圆估计与基本检查

拟先使用 OpenCV `fitEllipse`，得到中心、两轴长度及角度。实现时应确认长短轴与角度的约定，检查输入点数、点分布是否退化，以及输出参数是否有限且轴长有效。无法拟合时记录原因，并继续展示原候选。

拟合出的椭圆可能贴近错误区域。除拟合是否完成外，建议先记录以下描述量，用于观察，不立即规定统一通过门槛。

| 描述量 | 用途 |
| --- | --- |
| 候选与椭圆的面积及中心位置 | 观察是否只包住局部碎片，或扩得过大、偏得过远 |
| 长短轴比例、方向 | 观察极端扁长形状和倾斜是否有图像依据 |
| 椭圆内的原始肤色像素比例 | 检查椭圆是否得到颜色掩膜支持 |
| 椭圆中心部分与外围的肤色分布 | 检查是否出现外围头发围成椭圆、中心脸部却缺少支持的情况 |
| 候选像素落在椭圆内外的分布 | 观察哪些碎片被包含，哪些像素远离拟合范围 |

内部肤色支持应从填孔前的颜色掩膜计算。若先填满候选再统计，填孔引入的像素会掩盖原本缺少颜色支持的区域。

首轮展示多个候选及其依据。是否自动选一个最佳椭圆、如何排序以及不可靠时的处理，待观察结果后决定。

## 可视化与结果记录

每张图建议展示：

- 原图和原始肤色掩膜。
- 有编号的连通块，以及候选由哪些块组成。
- 候选掩膜、参与拟合的轮廓点。
- 叠加到原图上的椭圆。
- 椭圆与脸部真值的空间对照。

每个候选保存组成块、拟合参数、描述量和失败状态。页内需能区分不同候选，避免只展示事后效果最好的一个。

评估时可以把椭圆内部临时转成二值区域，测量其对真值脸部的覆盖和对非脸区域的包含情况，并结合 Precision、Recall、IoU 查看。此处测量的是粗定位形状，记录时应与实际分割掩膜指标分别命名。真值上的分数不能用于运行时选椭圆。

先检查定位较合理、明显偏移、只包局部碎片和包住错误背景等案例，再讨论总体表现。记录解释与证据的对应关系，尚未确认的原因保留为假设。

生成物拟使用独立的 Lab4 椭圆检查目录，保存配置、逐候选记录、逐图可视化和测量结果。具体目录与运行入口在实现时补充，既有图册和结果可用作参照。

## 根据结果决定后续用途

| 观察 | 可讨论的后续行动 |
| --- | --- |
| 原始肤色结果上已能较可靠地定位 | 尝试用粗椭圆限制连接、分离或补全范围 |
| 主要因碎裂造成椭圆过小或缺失 | 先连接或组合区域，再重新检查椭圆 |
| 主要被头发、脖子或背景带偏 | 先分离错误区域，或改进候选及轮廓点选择 |
| 正脸较可靠、侧脸或遮挡明显退步 | 分析适用条件，再决定何时采用椭圆约束 |

首轮以图像证据和可解释的描述量判断可行性。具体参数、排序规则及如何参与最终分割，仍需后续讨论和实验。

## 研究依据与适配范围

- Wang 与 Sung（1999）结合形态学、骨架和人脸结构确定轮廓点，再拟合椭圆。当前仅核实到出版社公开内容，本文的直接轮廓拟合是简化起步方案。见[论文页面](https://doi.org/10.1016/S0167-8655(99)00072-0)。
- Garcia 与 Tziritas（1999）根据距离和颜色组合区域，并检查候选整体及中心的肤色密度。把这些线索用于椭圆候选，是本项目的适配设想。见[论文全文](https://www.csd.uoc.gr/~tziritas/papers/01mm03-face_detection.pdf)。
- OpenCV 提供二维点集的椭圆拟合接口，至少需要五个点。具体接口见[官方文档](https://docs.opencv.org/4.13.0/d3/dc0/group__imgproc__shape.html)。

## 首轮实现记录（2026-11-08）

实现入口为 [build_gallery.py](../../experiments/lab4/ellipse_check/build_gallery.py)，候选生成和拟合放在同目录的 `ellipse.py`。起步参数与运行方式见 [实现说明](../../experiments/lab4/ellipse_check/README.md)。

本轮采用最小块面积 128 像素、外接框间距上限 32 像素、平均 Cr/Cb 距离上限 12。每块最多取两个符合条件的近邻，产生双块、三块组合；每条外轮廓最多采样 256 点。中心椭圆的轴长为完整椭圆的 60%。这些值是实施时的初始选择，尚未经过选参验证。

独立结果目录为 `results/lab4_ellipse_check_20261108/`，离线入口为 [index.html](../../results/lab4_ellipse_check_20261108/index.html)。默认展示最大的保留单块作为观察参照，可手动切换所有组合。实际拟合点、失败状态、几何参数和事后指标随结果保存，后续按图像反馈讨论参数及候选规则。

本次已运行全部 162 张图，产生 1,062 个单块候选和 1,436 个组合候选。其中 2,492 个得到与图像相交的有效椭圆，6 个拟合结果落在图像外；所有候选均保留状态。这里的“有效”指几何拟合及图像内栅格可计算，定位是否正确仍需检查。

`00578` 的默认候选明显包含头发，`00609` 的默认候选只形成局部小椭圆。这些现象提示后续应分别查看候选组成、拟合轮廓点和中心肤色支持。对应结果中已包含实际参数和生成程序快照。已完成资产完整性及页面搜索、翻页、候选切换的程序检查，浏览器排版由用户查看。
