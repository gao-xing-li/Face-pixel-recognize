# Lab4 一次“估计—修整”的实现设计

记录日期为 2026-11-08。小组认可先采用弱预操作支持椭圆估计，再根据椭圆进行局部修整的大致方向。本文记录首版设计，末尾保存实现入口与本轮运行结果。具体参数与候选评价方式仍属于待验证选择。

首轮之后，小组暂停了从肤色轮廓直接拟合椭圆的后段计算，将该路线收缩为面积前三个连通块的椭圆可视化。本文和一轮修整结果作为历史实验保留。后来完成的双眼引导修整见 [交接总览](操作方向与整体流程.md)。

## 目标与当前起点

希望先获得较可信的脸部范围，再有针对性地修复断裂、补充缺口和抑制外围背景。需要检查两项能力：前段是否改善了椭圆定位，后段是否在给定椭圆后改善了实际分割。

现有 `experiments/lab4/ellipse_check` 已完成原始肤色掩膜上的单块、近邻组合、外轮廓拟合和可视化。其全部候选可用于参照，默认最大单块只是浏览起点。当前结果说明，头发和背景会污染拟合点，脸部碎片也会产生局部小椭圆。

## 当前思路与首版范围

```text
原图 → 固定颜色阈值 → 原始掩膜 M0
                          ↓
             原始 / 轻量闭运算 / 轻量开运算
                          ↓
               多个单块与近邻组合候选
                          ↓
            椭圆估计及颜色、边界支持描述
                          ↓
            按每个候选椭圆独立修整一次
                          ↓
            原结果、椭圆范围、修整结果对照
```

保留 `M0`，后续的颜色支持和局部修整仍可使用其中的原始像素。弱操作的主要作用是提供更好的候选与拟合点。首轮先观察逐候选结果，候选自动筛选及椭圆反复更新根据结果再讨论。

## 1. 弱预操作

沿用既有肤色统计及起步阈值 `k=1.25`，从 `M0` 分别产生三个版本。

| 版本 | 拟采用的操作 | 待观察的问题 |
| --- | --- | --- |
| 原始 | 直接使用 M0 | 与已完成椭圆检查对应 |
| 轻量连接 | 小尺度闭运算 | 窄缝是否连上，背景是否同时接入 |
| 轻量分离 | 小尺度开运算 | 细桥是否切开，脸部是否受损 |

两个形态学版本分别从 `M0` 出发。这样可以区分连接和分离的作用。首轮核建议从 3×3 或 5×5 椭圆核、一次操作起步，实际采用值在实现配置中记录。

原始掩膜中的多个区域继续参与候选。极小块过滤仅用于控制候选规模，并记录过滤数量，原始图中仍可查看它们。沿用现有近邻组合逻辑作为起点，候选需记录来源版本和组成块 ID；不同版本的块 ID 不能直接视为同一区域。

## 2. 椭圆估计与支持描述

先复用外轮廓采样和 `fitEllipse`，比较弱操作前后实际拟合点与几何参数的变化。支持描述统一回到原始掩膜或原图计算，避免用形态学新增像素证明椭圆合理。

| 依据 | 首版可记录的量 | 用途 |
| --- | --- | --- |
| 原始肤色 | 椭圆内部、中心部分和外围的肤色比例 | 检查空心背景环、缺少支持的小区域 |
| 空间分布 | 椭圆内若干分区的肤色数量或比例 | 区分支持集中在局部与分布在多个部位 |
| 原图边界 | 椭圆周围窄带与相邻带的梯度强度 | 观察拟合边界是否有图像依据 |
| 候选关系 | 候选被覆盖比例、椭圆大小与候选大小 | 检查明显过大、过小、偏移的估计 |

原图边界可先采用灰度图的形态学梯度或 Sobel 梯度，选择一种形成固定起步实现。椭圆周围窄带由椭圆掩膜的膨胀、腐蚀之差产生。采样位置与梯度图应同时可视化。强边缘可能来自头发或背景，所以边界支持与内部肤色支持需要一起分析。

首轮各描述量分别展示，暂不固定复杂的加权总分。所有可用椭圆都可进行下一步修整，并通过可视化切换比较。默认最大单块或固定候选顺序仅用于展示，不使用真值选赢家。

## 3. 将椭圆划分为处理区域

对于中心、轴长和角度已确定的椭圆 E，保持中心与方向，通过轴长缩放得到内椭圆 Ein 和外椭圆 Eout。

| 区域 | 定义 | 初步用途 |
| --- | --- | --- |
| 内部 | Ein | 接受较强的连接、补洞等修整建议 |
| 边界带 | Eout 减去 Ein | 优先保留原有图像证据，观察不确定轮廓 |
| 外围 | Eout 之外 | 检查并抑制远离估计脸部范围的误检 |

内外缩放比例为新参数。起步可考虑内轴长 0.8 倍、外轴长 1.15 倍，属于本设计建议，待实现时记录和验证。现有椭圆检查中的 0.6 倍中心区域用于统计描述，两者用途不同。

裁剪到图像尺寸后的实际区域应保存或展示。椭圆触边、中心异常以及无有效内部区域的情况保留状态，不能仅据“拟合成功”就推断定位可靠。

## 4. 首版一次修整的具体建议

先给出一个容易观察的起步流程，各阶段保留对照。

1. 取局部输入 `Mlocal = M0 ∩ Eout`。它将外围抑制的影响与后续修补分开。
2. 从 `M0 ∩ Ein` 取得有颜色支持的内部种子 S。种子只是待验证的连接依据，其可靠性取决于椭圆和肤色判断。
3. 对 Mlocal 做中等尺度闭运算和填孔，得到修补建议 P。核尺寸建议首轮只取一个，例如 9×9，并沿用现有填孔及补零边界处理方式。
4. 仅在 Ein 内接受 P 的修补；边界带暂保留 Mlocal。得到 `Mproposal = (P ∩ Ein) ∪ (Mlocal ∩ (Eout − Ein))`。
5. 查看 Mproposal 的连通块，保留与种子 S 相交的区域。可以保留多块，记录此步删除了哪些像素。

这种安排使强修补集中在内部，边界带仍保留原始阈值证据。首轮边界轮廓可能仍有缺口，后续再根据结果研究边界支持下的修整。

如果没有内部种子或椭圆不可用，记录该候选未执行修整，并提供原始结果供查看。全自动流程遇到这种情况的回退策略，在候选选择确定后另行讨论。

上述步骤是本项目的简化方案。若填孔、连接使背景与内部种子连通，最后一步仍可能保留背景，因此必须展示逐步变化。椭圆过小也可能把正确脸部裁掉，这应计入修整代价。

## 5. 如何区分改进来自哪里

第一版应至少能逐候选查看下列三种输出。

| 输出 | 比较目的 |
| --- | --- |
| M0 与既有 Lab3 预测 | 参照原问题和已有方法 |
| 只做椭圆范围限制的 Mlocal | 测量椭圆定位和外围裁剪的作用 |
| 完成一次修整的结果 | 测量局部连接、填孔和种子关联的额外作用 |

候选较差却修整幅度很大时，应检查是否放大了错误。候选位置较好但修整退步时，再检查具体操作。若修整改善只来自外围裁剪，报告中需按实际作用解释。

先在验证集查看这些关系，并保留失效和无明显变化的案例。训练集或原测试集的扩展查看应标明用途，原测试集仍属于开发后分析。

## 6. 可视化、测量与文件管理

页面建议按“候选来源 → 椭圆 → 一次修整”组织，每张图可切换候选，查看：

- 原图、M0、弱预操作及候选组成。
- 拟合点、椭圆、内外处理范围、梯度图及边界采样带。
- Mlocal、种子、修补建议、最终修整掩膜。
- 新增或删除像素的位置，以及对应正确脸部或非脸区域。

对原预测、只限制范围和完整修整分别计算 Precision、Recall、F1、IoU，必要时观察 Boundary IoU。逐图指标、各阶段新增或删除的 TP/FP 和按划分汇总的计数分别保存。逐候选比较不能把同一张图的多个候选当作多张独立样本汇总。

真值只用于上述事后测量与误差图。选候选、拟合和修整使用原图与预测信息。首轮全图汇总可继续用最大单块的固定参照并注明有效图数；更合理的自动排序留待描述量与样例分析后确定。

实现时拟在 `experiments/lab4/` 下新建独立实验目录，复用现有椭圆模块和公共评价函数。新结果使用独立的 `results/lab4_...` 目录，并保存实际参数、来源版本、候选信息和运行说明。具体入口在实现时补充。

## 7. 文献启发与适配边界

- Chai 与 Ngan（1999）的局部肤色密度修整，为轻量整理肤色结果提供依据。首版开闭运算是较简单的起步对照。[论文全文](https://www.ee.cuhk.edu.hk/~knngan/TCSVT_v9_n4_p551-564.pdf)
- Garcia 与 Tziritas（1999）利用相邻区域、颜色和候选中心肤色分布产生及评价候选。这些线索支持前段候选估计。[论文全文](https://www.csd.uoc.gr/~tziritas/papers/01mm03-face_detection.pdf)
- Slabaugh 与 Unal（2005）的椭圆形状先验图割，在椭圆周围窄带分割后重新估计椭圆。其人脸示例具有受控暗背景和特定初始化条件。本文借用局部处理及形状先验思想，提出一次形态学修整，尚未验证其效果。[论文全文](https://perso.telecom-paristech.fr/bloch/VOIR/articles/cr2391.pdf)

本阶段以一次“估计—修整”观察效果，反复更新椭圆或引入更复杂的边界分割，需由首轮结果决定。

## 首版实现入口

首版程序位于 [estimate_refine/run.py](../../experiments/lab4/estimate_refine/run.py)，具体起步参数及操作说明见 [README](../../experiments/lab4/estimate_refine/README.md)。默认先运行 32 张验证图，可切换三个弱操作来源及其全部单块、组合候选。

本轮采用 5×5 弱开闭运算、9×9 内部闭运算，内外轴长比例为 0.8 和 1.15。边界描述选择原图灰度的 3×3 形态学梯度，四个分区以图像坐标下椭圆中心划分。描述量分别展示，候选自动排序仍待后续分析。

结果目录为 `results/lab4_estimate_refine_20261108/`，页面入口为 [index.html](../../results/lab4_estimate_refine_20261108/index.html)。汇总以每个来源的最大保留单块为固定参照，四个阶段在同一批修整成功图像上配对计算并注明有效图数。

## 本轮运行记录（2026-11-08）

已完成全部 32 张验证图的三种来源，共生成 1,832 个候选。1,826 个候选完成修整，2 个椭圆不可用，4 个没有内部肤色种子。各来源默认最大单块均有 32 张可配对图像，汇总结果如下。

| 候选来源 | 原始阈值全局 F1 | Lab3 最大块填孔 F1 | 仅限外椭圆 F1 | 一轮完整修整 F1 |
| --- | ---: | ---: | ---: | ---: |
| 原始 | 56.128% | 72.701% | 60.059% | 72.909% |
| 5×5 闭运算 | 56.128% | 72.701% | 59.690% | 72.421% |
| 5×5 开运算 | 56.128% | 72.701% | 59.016% | 66.519% |

这里采用固定默认候选，并未按真值选择每张图的最优候选。原始来源略高于 Lab3，闭运算与开运算来源较低，结果仍需结合候选及像素变化解释。

例如验证图 `00535` 的闭运算最大单块候选，从仅限制外椭圆到完成修整，新增正确脸部 10,197 像素、新增误检 677 像素，同时删除误检 1,651 像素；该图 F1 从 76.260% 变为 83.331%。这描述的是此图此候选中局部修整的作用。

已核对原始来源的椭圆与前一轮图册一致，96 个默认候选保存的最终掩膜与指标一致，并检查页面的来源切换、候选切换及翻页逻辑。过程图已做图片检查，浏览器排版由用户查看。
