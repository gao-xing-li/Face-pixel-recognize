# 实验四相关研究线索

本文保留初期调研时的文献事实、适配设想和未验证状态；后续已做实验及判断见 [交接总览](操作方向与整体流程.md)。下文的“尚未实现”指调研当时，不覆盖之后的简单开闭运算、椭圆和眼睛探索。

检索日期为 2026-11-08，对应[小组讨论方向](实验四小组讨论方向_2026-11-08.md)。本文将文献中的方法与本项目可尝试的改法分别说明，作为后续选型和讨论材料。以下尚未实现或在本项目数据上验证。

## 一、方向对应关系

| 小组方向 | 直接相关的已有方法 | 需要回答的问题 |
| --- | --- | --- |
| 人脸椭圆区域先验 | 正脸形态分析与椭圆拟合，五官及轮廓辅助的椭圆定位 | 椭圆从哪里来，怎样避免错误区域带偏位置和尺度？ |
| A：先合并脸部像素，再选最大连通块 | 小尺度闭运算，局部肤色密度修整，近邻肤色区域合并 | 脸部断裂的尺度多大，哪些连接会同时把背景接进来？ |
| B：把背景从粘连区域中分离出去 | 腐蚀或开运算断开细桥，结构与轮廓分析，标记控制分水岭 | 脸与背景通过窄连接粘连，还是已经大面积混合？分开后怎样选脸？ |

使用椭圆形结构元素，只是规定局部膨胀或腐蚀的邻域形状。使用人脸椭圆先验，还需要估计具体人脸椭圆的中心、长短轴和方向，并将其用于区域判断或处理约束。

## 二、椭圆先验

### 1. Wang 与 Sung，1999

**Frontal-view face detection and facial feature extraction using color and morphological operations**，Pattern Recognition Letters，20(10)，1053–1068。

肤色掩膜可能把脸、耳朵、脖子连成一块。作者结合二值形态学、人脸对称性与骨架结构，定位脸部轮廓点，再拟合椭圆，进一步定位五官。其方法同时涉及小组的椭圆先验和方向 B。

可借鉴之处是先研究哪些轮廓点可信，再估计椭圆。若直接把错误连通块的全部外轮廓交给拟合，拟合也可能跟随错误区域。面向本项目的简化尝试可以是比较候选区域的椭圆拟合质量，或用可信候选得到的椭圆约束后续连接和裁剪。后两项属于本项目适配设想。

论文以正脸为主要对象。侧脸、遮挡和严重碎裂时是否仍可确定轮廓，需要结合样例判断。本次核实了出版社可公开读取的摘要、引言和章节片段，骨架取点的具体规则仍需取得完整正文后确认。

[论文页面与 DOI](https://doi.org/10.1016/S0167-8655(99)00072-0)

### 2. Hsu、Abdel-Mottaleb 与 Jain，2001

**Face Detection in Color Images**，ICIP 2001。此处引用可获取的会议版本。

作者从肤色区域产生人脸候选，再构造眼睛、嘴和边界特征图，依据眼嘴几何关系及图像边缘，用 Hough 变换寻找脸部椭圆。五官提供方向等线索，使椭圆位置的确定有更多依据。建议看第 2.2 节与图 5。

对本项目的启发是把椭圆的确定与肤色大块的大小分开考虑。完整复现需要额外的五官定位工作；若只借用其思想，应写明简化了哪些环节。论文还使用了 Cb/Cr 颜色空间中的椭圆肤色模型，那是颜色分布模型，与图像平面上的人脸椭圆应区分。

[作者所在研究组提供的全文](https://biometrics.cse.msu.edu/Publications/Face/HsuMottalebJain_FaceDetection_ICIP01.pdf)

实现层面的椭圆拟合可以查 OpenCV 的 `fitEllipse`。输入是一组二维点，至少需要五个点；函数能完成拟合，可信输入点的选择仍是本实验需要解决的问题。

[OpenCV 椭圆拟合说明](https://docs.opencv.org/4.13.0/d3/dc0/group__imgproc__shape.html)

## 三、方向 A：尽量合并脸部碎片

### 3. Chai 与 Ngan，1999

**Face Segmentation Using Skin-Color Map in Videophone Applications**，IEEE Transactions on Circuits and Systems for Video Technology，9(4)，551–564。

作者先做肤色分割，再按 4×4 小块统计肤色密度。对密度图进行邻域规则修整，以减少孤立误检并补充密集肤色区域内的缺口，随后结合亮度分布和几何修整输出脸部区域。建议看第 III-B 节及图 8–10。

可单独借用密度修整阶段，比较其是否能把断裂的脸部区域连接起来，再选最大连通块。密度修整也可能扩展密集的背景误检；原论文以视频电话中的头肩图像为主要场景，邻域规则与后续亮度假设需在当前数据上检查。

[作者提供的全文](https://www.ee.cuhk.edu.hk/~knngan/TCSVT_v9_n4_p551-564.pdf)

### 4. Garcia 与 Tziritas，1999

**Face Detection Using Quantized Skin Color Regions Merging and Wavelet Packet Analysis**，IEEE Transactions on Multimedia，1(3)，264–277。

作者先量化颜色、找出相对均匀的肤色区域，再依据区域外接框的接近程度和颜色相似性逐步合并，产生多个人脸候选。之后用尺寸、长宽比、肤色密度和小波纹理筛选候选。第 III 节和图 4 直接展示了合并过程。

本项目可以借用“距离近且颜色相近才允许连接”的原则。需要注意，原论文主要合并候选框并输出人脸检测区域。若要改成精确二值掩膜，还需设计实际的连接路径，以及允许增加的像素范围。候选框合并不等于框内所有像素都属于脸。

[作者提供的全文](https://www.csd.uoc.gr/~tziritas/papers/01mm03-face_detection.pdf)

### 5. 小尺度闭运算与局部膨胀

闭运算依次膨胀、腐蚀，可连接尺度较小的缺口，适合作为方向 A 的简单参照。局部膨胀后选块也可以观察是否能让脸部碎片相接。核尺寸、形状和方向决定哪些间隙有可能被跨过；同样的操作也可能跨过脸与背景的间隙。

若结合椭圆先验，可以研究只在椭圆附近进行连接，或只接受有合理位置、尺度的连接结果。这属于待验证的组合设计。

[OpenCV 形态学操作教程](https://docs.opencv.org/4.x/d9/d61/tutorial_py_morphological_ops.html)

## 四、方向 B：从粘连区域中分离背景

### 6. 腐蚀、开运算与细连接断开

腐蚀可使前景缩小，并断开一些细窄连接；开运算先腐蚀再膨胀，可以清掉部分小噪声和细突出。对于脸部和背景只由窄桥相接的情况，可以先尝试小尺度操作，再观察连通块是否分开。

本项目需要同时检查两件事。第一，细桥是否真的位于脸与背景之间，还是脸部本身的细窄区域。第二，分离后最大的块是否仍然是背景。如果第二个问题存在，还需要候选选择规则或椭圆等信息，单纯断开连接不能完成选脸。

[OpenCV 形态学操作教程](https://docs.opencv.org/4.x/d9/d61/tutorial_py_morphological_ops.html)

### 7. Meyer 与 Beucher，1990

**Morphological Segmentation**，Journal of Visual Communication and Image Representation，1(1)，21–46。

论文提出以分水岭和标记控制为基础的形态学分割框架。可以把梯度图看成地形，为待区分的区域放置不同标记，再寻找它们之间的分界。

适配当前问题的思路是从图像推断脸部内部标记和背景标记，在原图梯度等信息上分割已经相连的区域。这能研究二值掩膜中连在一起、但原图中仍有边缘差异的情况。OpenCV 官方教程给出用距离变换、标记及 `watershed` 分开相互接触物体的完整示例。

脸部与头发等区域之间是否有足够边缘、标记能否可靠产生，是本项目需要验证的条件。椭圆内部与外部可作为构造标记的线索，但这属于适配设想；自动运行时标记应由图像或预测产生，真值只用于评价。

本次核实了原论文公开摘要及官方实现教程。原论文并非人脸专用方法，上述人脸应用属于本项目推导。

[原论文与 DOI](https://doi.org/10.1016/1047-3203(90)90014-M)；[OpenCV 标记控制分水岭教程](https://docs.opencv.org/4.x/d3/db4/tutorial_py_watershed.html)

### 8. 重建操作的一个适用边界

普通二值形态学重建会恢复约束掩膜中与标记相连的区域。如果用开运算先断开脸与背景的细桥，却随后在原始粘连掩膜中做充分重建，桥和背景可能被重新恢复。因此，将重建加入方向 B 时，要明确约束掩膜与停止条件。

重建更直接对应从可靠标记恢复连通区域，不能仅凭“重建”这个名称推断它能把同一原始连通块中的脸与背景分开。

[Vincent，1993，形态学重建原论文](https://telin.ugent.be/~sanja/StudentProj/Literature/vincent-93.pdf)

## 五、后续小组讨论可以落到的具体问题

1. 椭圆用于评价候选是否合理、限制操作范围，还是直接决定输出轮廓？不同用途对定位精度的要求不同。
2. 脸部断裂主要是窄缝，还是大面积颜色漏检？前者较适合局部连接，后者需要更多图像线索。
3. 背景粘连主要是细桥，还是与脸形成宽而连续的混合块？前者可先看开运算，后者需要研究轮廓、梯度或候选形状。
4. 合并与分离后如何选脸？如果最大面积假设仍不成立，椭圆或其他候选特征应承担什么作用？
5. 先分别观察单项操作的像素变化，再讨论组合顺序。记录预期、实际变化、解释与尚未验证的原因。

上述问题服务于后续选型。本记录保留小组尚未确定算法、参数和分工的状态。
