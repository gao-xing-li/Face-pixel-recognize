# 首次启动验证记录

日期：2026-10-29。本记录只说明评价工具的开发验证，不包含真实分割性能。

## 本地验证

- 环境：Windows，Python 3.12.14，NumPy 2.3.5，Pillow 12.3.0。
- `python -m unittest discover -s tests -v`：23 项检查全部通过，覆盖单图手算、正类参数方向、未定义指标、忽略区域、多图汇总，以及文件配对、重复图像、异常不产生部分结果、CLI 成功和失败返回值。
- 已通过 setuptools 构建 wheel，并安装到隔离的项目内目标目录；安装后的包可以运行模拟 demo。
- 三个模拟样例合计 TP=3、FP=1、TN=9、FN=1、有效像素=14，与预先手算的计数一致。
- 已查看生成的“原图—真值—预测—错误图”，四个面板与混合错误样例对应。

临时文件目录设在项目工作目录内，以适应当前工作环境的写入范围。项目本身不依赖本机绝对路径。
