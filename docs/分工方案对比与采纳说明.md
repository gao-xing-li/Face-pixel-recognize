# 分工方案对比与采纳说明

更新日期：2026-10-28。

## 一、对比来源与整合结论

本次对比的是两份分工设计，尚无两套算法代码或实验结果可供性能比较。

- **仓库原方案**：[原始版本的分工文档](https://github.com/gao-xing-li/Face-pixel-recognize/blob/8eee10d8add0a56a0c03183915d409aa82a93960/分工文档.md)，标题为《基于颜色空间的人脸肤色像素检测系统：小组分工与依赖说明》。优点是技术约定、依赖关系和复现要求具体，部分接口与推进步骤规定较细。
- **补充方案**：用户提供的 `42689e007a1ab78682b57345c5300414_7902985393233882524_m.md`，标题为《实验3：基于颜色信息的亚洲人脸分割——小组分工与实验设计》。[原文归档](参考方案/补充分工方案.md)。优点是贴近题目，负责人自主范围明确，基础版和可选辅助处理的关系清楚。

**最终以补充方案组织工作，采用仓库原方案中保证数据、接口和评价一致的必要约定。** 两版共同采用的内容继续保留；对存在差别的内容，按下表明确取舍。后续以根目录的[整合版分工文档](../分工文档.md)执行。

## 二、逐项对比与具体采用内容

| 比较项 | 仓库原方案 | 补充方案 | 最终采用与理由 |
| --- | --- | --- | --- |
| **任务表述与边界** | 明确是像素级肤色检测，区别人脸定位/身份识别，并提示亚洲样本依据 | 直接对应“基于颜色信息的亚洲人脸分割”题目 | **合并采用**：用补充方案的课程题目组织项目，保留原方案对像素分割、其他皮肤误检和人群范围的说明，避免报告夸大能力 |
| **三人职责主线** | A 数据统计、B 算法整合、C 评价与报告整合，并列出 AI 辅助任务 | A 数据建模、B 分割验证调参、C 独立测试分析 | **以补充方案为主，保留共同分工**：B 明确承担验证和代码整合，C 承担独立测试与报告整合；各自核验自己的章节 |
| **基础模型** | 单一颜色空间优先 YCbCr，较具体地约定 Cb/Cr 双通道与均值 ± kσ | 优先 YCbCr 和均值、方差，A 决定统计细节，B 决定实际使用规则 | **采用补充方案的自主范围，保留原方案作默认实现**：Cb/Cr 双通道阈值可直接起步，但不预先锁死所有分量和参数 |
| **辅助处理** | 以逐像素阈值分类为主，未单列可选增强流程 | 明确先基础版，按需加入预处理、形态学、连通区域、形状或模板过滤 | **采用补充方案**：由 B 根据验证效果选择；保留基础结果，只比较实际尝试或采用的处理，不要求全部完成 |

| **数据划分责任** | A 负责训练/验证准备并汇总全局划分，C 负责测试真值质量核查 | A 统一划分训练、验证、测试集，C 核对测试数据与标签 | **采用补充方案的责任划分**：A 维护唯一全局清单，C 独立核查测试集与重叠，避免测试集准备责任悬空 |
| **B 调参是否依赖 C** | 依赖表已允许“C 的指标或 B 的验证实验”，流程另写 C 反馈验证指标 | 明确 B 自行准备调参评价程序，不依赖 C 先完成模块 | **采用补充方案并消除流程歧义**：B 可独立推进验证；C 提供核查和建议，不构成选参前置依赖 |
| **阈值候选与选参指标** | 建议预实现 k=1、1.5、2、2.5、3，并建议 F1、IoU | 候选范围、选参指标及最终规则由 B 决定 | **采用补充方案**：k 列表降为起始参考；保留原方案的 F1/IoU 建议，B 记录最终指标和取舍依据 |
| **接口确认时机** | 以“先约定接口，再并行开发”为主，开工前一次性确认字段和函数 | 先交付样例和必要说明，内部实现自主，跨模块变化及时沟通 | **采用补充方案的推进方式，保留原方案的必要语义**：先对齐标签、通道、尺寸和参数含义；具体函数、字段与目录不作为开工门槛 |

## 三、本次补充澄清的交接内容

以下内容是为消除两版衔接中的空缺而补充，不代表已有实现或实验结论：

1. **固定配置可复现**：B 交接时一并记录训练统计及划分版本、最终阈值、预处理、辅助处理、运行方式和输出约定，避免只交一个 `k` 值而遗漏处理步骤。
2. **多图指标口径一致**：区分全局累加混淆矩阵后计算与逐图平均，明确分母为零、忽略区域和无正类图像的处理。B 的验证与 C 的测试保持一致。
3. **独立测试不等于重复写代码**：C 可以复用 B 的评价函数，但独立核查测试清单、配置与结果；具体代码复用方式由 B/C 协商。
4. **区分方案与成果**：建议目录、默认接口和候选参数不表示已经实现；当前没有可宣称的准确率、数据规模或已验证改进。

## 四、保留为可选项的内容

不把特定数据集、全部 k 值、多颜色空间比较、全部辅助处理、固定目录或固定函数名列为必做项。A/B/C 在必要交接约定内自主决定；有变化时同步对应说明。
