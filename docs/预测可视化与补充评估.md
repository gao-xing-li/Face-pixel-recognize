# B 预测可视化与补充评估

本次使用已经完成独立测试的 32 张图及两套固定预测，生成效果图并从其他角度描述结果。开始前重新核对原图、真值、有效区域和预测文件的哈希，并复算原有计数；B 算法、参数和正式像素指标均保持不变。

## 1. 效果图如何看

| 文件或目录 | 内容与用途 |
| --- | --- |
| `prediction_examples.png` | 原图、人工真值、B 最终预测抠图和误差叠加，包含成功、严重漏检和明显误检 |
| `baseline_final_comparison.png` | 原图、真值、基线、最终预测、最终误差；展示选定的代表样例 |
| `per_image/` | 全部 32 张测试图的六宫格，避免只展示好看的例子 |
| `transparent_cutouts/` | 用 B 最终掩膜直接作为 alpha 的透明 PNG，可插入报告 |
| `sample_stability.png/.svg` | 逐图基线—最终散点图和 F1 累积分布 |
| `boundary_and_errors.png/.svg` | 边界带重合与误检/漏检像素占比 |
| `uncertainty.png/.svg` | 按图像配对重采样的 F1 差值区间 |
| `brightness_groups.png/.svg` | 探索性亮度分组对比 |

误差叠加图中绿色为 TP、红色为 FP、蓝色为 FN、黄色为忽略区。棋盘格是透明抠图的显示背景。所有掩膜都来自实际 B 预测，未用真值修补预测。图像仅为排版缩放，指标始终在原始 512×512 像素上计算。

代表图按明确规则选择：最终 F1 最高、最接近 F1 中位数、F1 提升最多、下降最多、Precision 最低。同一图满足多个规则时合并说明。本次 00570 同时是最接近中位数和提升最多的图，因此共展示 4 个不同样例；简版总览展示 00610、00609、00718。完整 32 图均包含在输出包中。

## 2. 逐图稳定性：平均分之外看尾部

| 逐图 F1 描述 | 基线 | 最终 |
| --- | ---: | ---: |
| 平均值 | 0.628321 | 0.680803 |
| 中位数 | 0.663526 | 0.777520 |
| 25% 分位数 | 0.495331 | 0.627634 |
| 75% 分位数 | 0.762593 | 0.871591 |
| 最小值 | 0.272936 | 0.031261 |
| 最大值 | 0.906781 | 0.929953 |

最终方案有 27 张图的 F1 提高、5 张降低。中位数和大部分样本表现改善，但最差样例下降很大。因此，报告应同时展示分布和失败案例，不能用一个总体分数概括每张图的表现。

## 3. 边界质量：Boundary IoU

补充使用 [Boundary IoU（CVPR 2021）](https://openaccess.thecvf.com/content/CVPR2021/html/Cheng_Boundary_IoU_Improving_Object-Centric_Image_Segmentation_Evaluation_CVPR_2021_paper.html)，根据预测和真值各自的内侧边界带计算交并比，参照[作者实现](https://github.com/bowenc0221/boundary-iou-api/blob/master/boundary_iou/utils/boundary_utils.py)。本次带宽是图像对角线的 2%，在 512×512 上为 14 像素；用 3×3 方形腐蚀迭代实现，图像物理边缘也计入。

| 逐图 Boundary IoU 平均 | 基线 | 最终 |
| --- | ---: | ---: |
| 32 张有效样本 | 0.152965 | 0.232769 |

该指标补充观察轮廓是否贴合，不取代原有 Mask IoU。这里报告的是逐图等权平均，不与全局 Mask IoU 混称为同一口径。空并集为 null，均值排除未定义值并记录有效图数；当前两方案均为 32 张。

本实现对忽略区域额外排除其带宽邻域，避免把忽略区的人工边缘计分。当前测试集没有忽略像素，因此结果不受该扩展影响。相关手算覆盖平移方块、整图前景和忽略区域。

## 4. 不确定性：按图像配对 Bootstrap

使用同一组图像索引配对重采样 10,000 次，种子 42，报告 percentile 95% 区间；每次先累加图像计数再计算总体 F1。单个像素没有被当作独立样本。[配对重采样方法说明](https://docs.scipy.org/doc/scipy/reference/generated/scipy.stats.bootstrap.html)

| 比较口径 | 观察差值，百分点 | 重采样区间，百分点 |
| --- | ---: | --- |
| 最终－基线：总体 F1 | +8.03 | [+3.57, +12.00] |
| 最终－基线：逐图平均 F1 | +5.25 | [-0.68, +10.60] |

两者分别对总体像素计数和等权图像平均作比较，统计对象不同。逐图平均改善的区间跨过 0，提示少数严重退步的图增加了波动。这些区间仅描述当前 32 张所选图像的重采样变异，不保证总体覆盖率，不作为因果或普遍显著性的证明。

## 5. 探索性亮度分组

按真值脸部有效区域的平均 Y（0–255 编码）排序，将当前 32 张图等分为三组。分组是事后描述，不是官方光照标注，平均 Y 也不是人群属性标签。

| 相对亮度组 | 图像数 | 平均 Y 范围 | 基线全局 F1 | 最终全局 F1 |
| --- | ---: | --- | ---: | ---: |
| 较低 | 11 | 103.9–150.9 | 0.565634 | 0.528162 |
| 中间 | 11 | 152.4–162.7 | 0.619034 | 0.748771 |
| 较高 | 10 | 162.7–205.0 | 0.694349 | 0.829979 |

本次较低亮度组的总体 F1 反而下降。它提供了进一步排查的线索，但亮度同时受到光照、曝光、成像和场景内容等影响，不能直接推出“低亮度导致失败”。原有测试失败案例、颜色偏移和背景混淆仍需结合图像解释。

## 6. 后续值得补充的评估

1. **明确场景标签后分组。** 先写清标注规则，再人工标注背景复杂度、遮挡、明显偏色和姿态，记录各组数量。当前没有这些已确认标签，不自动生成所谓官方场景分类。
2. **固定模型的鲁棒性压力测试。** 对亮度、白平衡或压缩做预先规定的扰动，记录性能变化；保持参数不变，并与现有独立测试区分。
3. **计算效率。** 固定硬件与分辨率，预热后报告单图中位数和 P95，区分读图、颜色转换、后处理与整体耗时。本次尚未计时，不能从已有运行日志推导推理延迟。
4. **人工检查标签边界。** 复核少量争议样例，区分算法错误和标注边界含糊。继续使用 A 已确定的脸部语义，不为提高分数切换成肤色标签。

优先写入报告的组合是：原有 Precision/Recall/F1/IoU、误差对照图、逐图分布和边界指标。当前二分类口径下 Dice 等于 F1，单纯再添加 Dice 不增加新的评价角度。

## 7. 复现命令与记录

安装作图依赖后，在 C 分支运行：

```text
python -m pip install -e ".[analysis]"
face-pixel-visualize --manifest data/processed/part_a/split_manifest.csv --run results/independent-test --output results/visual-assessment
```

已有 B 锁定环境时也可用该解释器，以 C 的 src 作为 PYTHONPATH 执行 `python -m face_pixel.visualization`。字体默认查找 Windows 微软雅黑或 Noto CJK，其他环境通过 `--font` 指定支持中文的字体。输出目录必须是新目录。

轻量结果见 [analysis_summary.json](../artifacts/part_c/visual_assessment/analysis_summary.json)、[逐图 CSV](../artifacts/part_c/visual_assessment/per_image_assessment.csv)。图像存于下载包，Git 保存生成代码与数值记录。分析 JSON 记录原始运行文件字节哈希、输入清单哈希、分析源码哈希、运行库版本、区间和选图规则；原始 JSON 换行会影响字节哈希，复现时使用对应的实际运行文件。

C 测试集现有 51 项并通过。另已检查代表总览、单图及四组统计图的排版，透明 PNG 的 alpha 与实际 B 预测一致，原有像素结果未改变。所有新增分析均为固定测试结果的事后补充，不构成新一轮独立测试，也没有用于重新选参。
