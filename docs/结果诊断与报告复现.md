# 运行说明与结果复现

检测与评价已合并到同一项目，使用 README 的安装和运行命令即可。不再需要检测副本、第二个 Python 环境、源码哈希或精确版本核验。

```text
python -m pip install -e .
face-pixel-prepare
face-pixel --output results/comparison
face-pixel-visualize --manifest data/processed/face/manifest.csv --run results/comparison --before original --after final --output results/visualization
python scripts/analyze_error_stages.py --output results/stages
```

实验输出按 baseline、original、final 命名。experiment.json 保存两种方法的差值和各方法的总体及逐图平均指标，evaluation 保存逐图计数及四幅对照，predictions 保存实际评价的掩膜。可视化输出全部测试图的六幅对照和透明抠图，并统计边界质量和逐图波动。

只重跑某一部分可以调用 python -m face_pixel.validation validate 或 predict。用 --help 查看参数。scripts/analyze_error_stages.py 用同一检测实现拆出 k=1.5、k=1.25、最大区域和填孔四个阶段，统计误检、漏检及原始类别来源。

报告入口是 report/人脸分割实验报告/main.tex，使用 XeLaTeX 编译，同目录 main.pdf 为阅读版。正文保留原实验和开发后的形态学补全比较，背景章节与个人信息仍留空。原始记录在 artifacts 中保留，历史记录内的哈希和版本字段不再作为运行条件。
