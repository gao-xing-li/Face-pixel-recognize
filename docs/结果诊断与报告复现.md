# 结果诊断与报告复现

报告入口为 `report/人脸分割实验报告/main.tex`，阅读版为同目录 `main.pdf`。使用 XeLaTeX 编译，报告中的背景章节和封面个人信息保留空白。

训练数据固定于 `1389a77158ab484dbdbbbb4e4e2f4d1c46a9625b`，检测流程固定于 `19e1d7409991c5896dfca9a6ef03694d2276a152`。最终规则为 k=1.25、最大连通域和填孔。32 张测试图的总体 F1 为 0.706933，IoU 为 0.546710。

`artifacts/part_c/error_diagnosis/` 保存四阶段计数、逐图记录、语义错误来源和输入哈希。中间掩膜用于解释固定结果，基线和最终掩膜均与原预测逐像素一致。

在已准备好数据清单、固定运行记录和检测源码副本的环境中，可重新生成诊断记录。

```text
python scripts/analyze_error_stages.py --manifest data/processed/part_a/split_manifest.csv --run results/independent-test --b-root ../detector-source --output results/error-diagnosis
```

运行时使用检测流程锁定的 Python、NumPy、OpenCV 和 Pillow 版本。输出目录必须是新目录。入口核对原输入和固定源码，再重新计算阶段变化与原始类别错误。报告保留四个案例、参数曲线、逐图分布、边界分布和重采样区间，重复数值由表格统一承载。

## 形态学补全附加实验

检测更新固定于 `40e7b48439e6eb95ba1825ea8c76ff391f2fc5a1`，原方法保持 `19e1d740` 的结果。配置、128 张预测掩膜、逐图计数、语义来源和图像配对重采样记录保存在 `artifacts/part_c/supplementary_morphology/`。复测前先通过两套配置的验证成绩复现，再检查 64 张原方法预测与原实验逐像素一致。
