# Lab3 运行说明与结果复现

检测与评价已合并到同一项目，使用 README 的安装和运行命令即可。不再需要检测副本、第二个 Python 环境、源码哈希或精确版本核验。

```text
python -m pip install -e .
face-pixel-prepare
face-pixel --output results/comparison
face-pixel-visualize --manifest data/processed/face/manifest.csv --run results/comparison --before original --after final --output results/visualization
python scripts/analyze_error_stages.py --output results/stages
```

实验输出按 baseline、original、final 命名。experiment.json 保存两种方法的差值和各方法的总体及逐图平均指标，evaluation 保存逐图计数及四幅对照，predictions 保存实际评价的掩膜。可视化输出全部测试图的六幅对照和透明抠图，并统计边界质量和逐图波动。

只重跑某一部分可以调用 python -m face_pixel.validation validate 或 predict。用 --help 查看参数。scripts/analyze_error_stages.py 用同一检测实现拆出 k=1.5、k=1.25、最大区域和填孔四个阶段，统计误检、漏检及原始类别来源。

Lab3 的完整结果和独立测试口径见 [Lab3 运行逻辑](完整运行逻辑与独立测试.md)，原始记录保留在 [artifacts](../artifacts/)。本分支的 [实验报告](../报告.pdf) 以 Lab4 为主体，第 1 章回顾 Lab3。Lab4 的流程、复跑和中间图册见 [Lab4 交接总览](lab4/操作方向与整体流程.md)。


重新搜索参数与重算训练统计（均使用新的输出路径）：

```text
python -m face_pixel.validation validate --plan configs/validation_plan.json --output results/validation-original
python -m face_pixel.validation validate --plan configs/morphology_plan.json --output results/validation-morphology
face-pixel-fit --params results/refit/skin_params.json --output results/refit
```

已有派生目录时复用 manifest；重新准备可指定 `face-pixel-prepare --output results/new-face-data`，随后显式传入新 manifest。源 CSV 路径相对项目根目录，派生与预测 CSV 路径相对各自目录。

当前诊断脚本只复算原方案的四阶段计数与语义来源，不再生成旧版阶段作图或原 frozen-method 对照脚本的完整追踪记录；需要历史记录的精确结构时检出对应提交。新旧补全比较使用 `python tools/compare_morphology.py --output results/morphology-comparison` 或 README 的统一入口。当前 requirements-lock.txt 不锁精确版本，历史环境见 artifacts 的原始记录。
